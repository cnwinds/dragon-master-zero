# 龙师零号

《龙师零号》是一款以"训练机器人学习舞龙"为核心的互动叙事游戏。玩家不直接操纵机器人，而是通过动作编排、自然语言口令和有限次数的现场纠偏，教会机器人理解节奏、协作与舞龙背后的"分寸"。

- 英文名称：Dragon Master Zero
- 游戏类型：2D 节奏策略、动作编排、互动叙事
- 目标平台：PC 浏览器与手机横屏
- Demo 时长：12–15 分钟
- 视觉方向：水墨竹刻 × 机械蓝图（全部程序化生成，零外部素材）
- 音频：Web Audio 合成鼓点/锣/竹音，完全离线

## 快速开始

```bash
npm install     # 安装依赖
npm run build   # 类型检查 + 单元测试构建 + 前端/服务端生产构建
npm start       # 启动生产服务，打开 http://localhost:4173
```

开发模式（前端热更新 + API 服务）：

```bash
npm run dev     # Vite(5180) + Node API(4173)
```

测试：

```bash
npm test        # 32 个单元测试（时间轴规则/口令解析/确定性/三结局路径/记忆系统）
```

## 在线 AI 口令解析（可选）

不配置任何密钥时，游戏使用本地离线关键词解析，功能完整。要启用在线大模型解析口令：

```bash
cp .env.example .env   # 填入 OPENAI_BASE_URL / OPENAI_API_KEY / OPENAI_MODEL
```

密钥只从服务端环境变量读取，绝不进入前端包；在线失败自动降级到本地解析，游戏流程永不阻断。

## 玩法一句话

> 动作竹简决定"做什么"，训练口令决定"怎么做"，鼓点只在关键拍纠偏——而最终阿零是否回头，取决于你教过它什么。

## 三条标准路径（可稳定复现）

- **表现路径**：腾跃为主 + 高表现口令 + 「抢先争彩」→ 冠军机器
- **守护路径**：探盘回望 + 稳定协作口令 → 灯散之后
- **平衡路径**：观察衔接 + 一次高难 + 「回望同伴」记忆 → 真正出师

## 目录结构

- `docs/` — 设计文档（GDD / 技术规格 / 场景画面规格 / 验收标准 / 制作计划）
- `docs/scenes/` — 逐场景画面、动画、布局、交互和素材规格
- `shared/` — 前后端共享类型与口令解析
- `src/game/systems/` — 确定性演出引擎、评分、记忆、结局判定
- `src/game/scenes/` — Phaser 场景（标题/序章/训练/演出/复盘/结局）
- `src/ui/` — DOM 界面层（竹简/鼓谱/口令/鼓面/印章）
- `server/` — Express 静态托管 + `/api/interpret` 代理与降级
- `tests/` — Vitest 单元测试
