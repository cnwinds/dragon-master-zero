# 《龙师零号》60秒实机宣传视频分镜

版本：0.2  
目标比例：16:9  
目标规格：1920×1080、60fps  
视频性质：以真实游戏画面为主，不制作与实际玩法不符的概念预告

## 1. 视频目标

60秒内回答四个问题：

1. 玩家是谁：机器人的训练员。
2. 玩家做什么：编排动作、输入口令、有限纠偏。
3. 游戏特别在哪里：机器人自主执行，训练方式改变结果。
4. 游戏讲什么：教会动作容易，教会分寸很难。

### 统一形象规则

- 全片使用 `CHR-AZERO-001`、`PROP-DRAGON-001` 和固定舞龙队母版。
- 首页、实机演出和结局镜头只改变姿态、镜头、光照与细节等级，不使用为宣传片重新生成的角色造型。
- 若使用AI生成补充画面，必须附带锁定母版参考图并通过叠图一致性验收。
- 无法由实际游戏共用资产还原的镜头不得进入成片。

## 2. 60秒主版本

### 00:00–00:04｜失败开场

画面：

- 夜色中的灯会舞台。
- 阿零猛然抬起龙头，身后的龙身被拉乱。
- 画面以朱砂校正线短暂停住。

声音：

- 一声重鼓。
- 竹架碰撞声。
- 周师傅短句：“你只看见了终点。”

字幕：

> 它能完成动作。

目的：先展示冲突，不先解释世界观。

### 00:04–00:09｜问题建立

画面：

- 阿零身体仍朝前，只用头部蓝图扫描缝扫过身后的队伍。
- 机械蓝图线扫描龙头与队形。
- 镜头切到训练桌上的动作竹简。

字幕：

> 但它还看不见身后的人。

声音：

- 鼓点由单拍进入稳定四拍。

### 00:09–00:18｜动作编排

画面：

- 玩家依次拖入“探、穿、回望、盘”等动作。
- 八拍鼓谱逐格点亮。
- 两组不同编排快速对比：一组稳定，一组冒险。

字幕：

> 编排每一个动作

操作要求：

- 必须录到真实拖放或触控过程。
- 鼠标移动保持简洁，不在界面上来回寻找。

### 00:18–00:27｜自然语言训练

画面：

- 玩家输入：“先看清灯阵，再大胆跃起。”
- 四项训练倾向从蓝图线中展开。
- 界面显示简短理解结果：“先稳后快，跃起前确认队形。”

字幕：

> 用一句话，告诉它你的意图

声音：

- 机械确认音与竹片敲击声叠加。

注意：

- 使用已经验证并缓存的真实模型响应。
- 不展示 API 地址、模型密钥、调试信息或加载失败重试。

### 00:27–00:39｜自主演出

画面：

- 阿零开始按照编排自主舞动龙头。
- 蓝色预测轨迹与竹青实际轨迹同时出现。
- “穿”顺利通过第一盏灯。
- “跃”出现过冲，朱砂失误标记闪现。

字幕：

> 然后，接受它自己的答案

声音：

- 鼓点加速。
- 保留一次轻微失误声，证明画面并非纯演出动画。

### 00:39–00:46｜限次纠偏

画面：

- 关键鼓点收束圆环出现。
- 玩家命中鼓面，失控轨迹被拉回。
- 界面短暂显示“正拍”和剩余一次纠偏。

字幕：

> 你只有两次纠正机会

声音：

- 正拍命中使用全片最清晰的一次鼓声。

### 00:46–00:56｜终局回望

画面：

- 00:46.0–00:47.2：中景，小满被灯绳绊住，阿零与小满之间的龙身突然绷直。
- 00:47.2–00:48.0：蓝色预测轨迹仍指向前方高点，镜头保持连续。
- 00:48.0–00:49.0：阿零停顿，蓝线继续闪烁，鼓点留出半拍空白。
- 00:49.0–00:51.0：阿零的头部、躯干和龙头依次回转，竹青实际轨迹偏离蓝线并朝队伍闭合。
- 00:51.0–00:52.0：小满重新站稳并回应，后续龙身逐节恢复波动。
- 00:52.0–00:54.0：队伍共同完成剩余高点动作，证明“回望”不是放弃精彩。
- 00:54.0–00:56.0：完整龙身与河面倒影凝固为竹刻定格，朱砂“出师”印章落下。

字幕：

> 精彩与分寸，能否在同一拍完成？

声音：

- 预测轨迹出现时鼓点停半拍。
- 阿零自主偏离蓝线时加入一声竹片回响。
- 共同抬龙后鼓、锣和环境人声同时回归，在定格时收束。

### 00:56–01:00｜标题

画面：

- 《龙师零号》标题。
- 英文标题：DRAGON MASTER ZERO。
- 下方依次出现“AI可以学会动作”和“但技艺，需要被传递”。
- 最后一秒只保留“可运行 Demo / AIGC 互动叙事游戏”。

声音：

- 阿零：“师傅，下一拍呢？”
- 一声轻鼓结束。

旁白应使用原创录音或明确授权的声音。若使用 AI 配音，必须在 AI 使用台账中记录工具、模型、生成日期和人工后期处理。

## 8. 录制要求

- 使用生产构建，不录制开发服务器报错或调试面板。
- 关闭浏览器地址栏、通知、鼠标高亮插件和无关窗口。
- 使用固定随机种子，确保演出结果可复现。
- 在线口令提前完成接口测试，并保留缓存结果。
- 终局回望使用一条连续镜头，不混剪其他结局。
- 单独录制游戏音频，避免麦克风环境噪声。
- 字幕保持在移动端安全区域内。
- 不使用未经授权的字体、音乐、图片、赛事标志或影视片段。
