# 场景05：第一轮——训练复盘

场景ID：`ReviewScene / trial-1`  
目标时长：30–45秒  
核心目的：解释本轮因果，并让玩家第一次主动选择会影响后续的训练记忆  
情绪：看懂结果 → 接受不完美 → 作出教学选择

## 1. 总体构图

复盘不是统计后台，而是一张铺开的“训练竹谱”。

- 背景保留竹棚最后一帧，饱和度降至28%，亮度降低18%。
- 中央放置本轮实际轨迹的竹刻路径图。
- 右侧显示四枚评价印章。
- 下方显示两条因果说明。
- 最下方展开两块候选记忆签。

镜头固定，不使用景深，所有信息必须一次看清。

## 2. 桌面布局

### 复盘标题

位置：`x=96 / y=62 / w=700 / h=70`

内容：

- `第一轮复盘`
- 右侧小字：玩家所选示范口令摘要。

标题下方一条竹刻横线连接到中央路径图。

### 轨迹复盘图

位置：`x=96 / y=150 / w=1120 / h=430`  
层级：`z=300`

内容：

- 米白竹纸底。
- 八拍路径从左向右排列。
- 蓝图预测线透明度28%。
- 竹青实际轨迹100%。
- 朱砂标记只保留本轮最重要的两个问题。
- 时间轴拍点刻在路径图下边缘。

交互：

- 移入或轻触某一拍，放大该拍至130%。
- 右侧出现“动作、原因、结果”三行说明。
- 不允许修改历史。

### 四维评价印章

位置：`x=1260 / y=150 / w=560 / h=230`

四枚印章按2×2排列：

- 稳
- 韵
- 合
- 意

规格：

- 单枚 `230×92`。
- 左侧大字，右侧0–100数字和一句短评。
- 分数不是进度条，使用印泥覆盖面积表现高低。
- 最高项先落印，最低项最后落印。

### 角色反馈

位置：`x=1260 / y=410 / w=560 / h=170`

根据表现显示两段：

- 周师傅评论基本功。
- 小满评论队伍感受。

每段不超过32个汉字，不使用笼统“不错”“再接再厉”。

示例：

- 周师傅：“探过再穿，灯柱没碰。这个顺序记住。”
- 小满：“你回头那一拍，我不用追着龙头跑了。”

### 因果说明

位置：`x=96 / y=610 / w=1724 / h=135`

左右两栏：

1. 动作因果。
2. 口令或纠偏因果。

每栏包含：

- 图标。
- 发生的具体行为。
- 对应画面小缩略。
- 影响的评价和隐藏状态方向。

示例：

- “探后接穿：路径风险下降，稳 +12。”
- “正拍纠偏：下一动作回到鼓点，韵 +8。”

### 候选训练记忆

位置：`x=250 / y=785 / w=1420 / h=190`

两块记忆签并排：

- 左记忆：`x=250 / w=660`
- 右记忆：`x=1010 / w=660`
- 高度170。

每块包含：

- 记忆名称。
- 触发证据。
- 下一轮效果。
- 可能代价。
- 小型竹刻图标。

第一轮可能出现：

- 先探后穿。
- 回望同伴。
- 稳住龙头。
- 均衡起势，作为候选不足时的基础记忆。

## 3. 进入动画

总时长1600毫秒。

### 0–500毫秒

- 演出实际轨迹压平并落入中央竹纸。
- 背景去饱和。
- 一声纸张铺开声。

### 500–950毫秒

- 四枚印章依次落下，间隔120毫秒。
- 每次落印使竹纸轻微下压2像素。

### 950–1250毫秒

- 两条因果说明从对应轨迹点延伸出来。
- 不使用箭头飞入，使用竹刻连线生长。

### 1250–1600毫秒

- 两块记忆签由底部推入。
- 此时开放交互。

玩家点击可跳过动画，直接显示最终状态。

## 4. 记忆选择交互

### 聚焦

- 记忆签向上移动8像素。
- 竹纹从暗到明。
- 中央路径图高亮产生该候选的证据拍位。

### 选择

点击后先进入预确认：

- 选中的记忆签扩大至104%。
- 另一块降至45%透明度。
- 阿零右肩或腰侧出现对应“记忆签”投影。
- 按钮显示“刻入记忆”。

确认后：

- 朱砂小印落在记忆签右下。
- 记忆签化为一条竹片，沿蓝图线进入阿零胸腔。
- 播放阿零一句短反馈，例如：“记录：先观察，再穿越。”

### 取消

- 在确认前可返回重选。
- 确认后本轮不能更改，除非重新开始整个关卡。
- 不提供付费或消耗品重选。

## 5. 未触发说明

第一轮选择后立即展示“下一轮如何触发”：

- 先探后穿：在穿之前安排探或回望。
- 回望同伴：在高风险动作前安排回望。
- 稳住龙头：在纠偏后观察恢复速度。
- 均衡起势：首个动作采用非高风险动作。

该说明持续3秒，也可在下一轮记忆栏中重新查看。

## 6. 下一步

确认记忆后，右下出现：

- 主按钮：`前往老街灯阵`
- 次按钮：`重看演练`

重看演练：

- 只播放本轮最后一次演出。
- 不重新计算结果。
- 可暂停并查看轨迹。
- 返回后保持记忆选择状态。

## 7. 用户交互

- 点击轨迹拍位查看说明。
- 点击四维印章查看构成，但不显示隐藏状态精确值。
- 选择一条记忆。
- 重看或继续。
- Escape打开暂停。

禁止：

- 在复盘中直接修改分数。
- 同时选择两条记忆。
- 跳过记忆选择进入下一轮。

## 8. 声音

- 竹纸铺开。
- 四枚印章使用不同力度，但保持同一材质。
- 高分印章声音更实，低分印章声音更轻，不使用失败蜂鸣。
- 记忆签聚焦为竹片轻擦。
- 刻入记忆为竹刻刀落下与低机械确认音组合。
- 背景音乐只保留单根低音持续音，给玩家阅读空间。

## 9. 手机横屏

- 轨迹图占上方55%。
- 四维印章缩为一行四枚，只显示大字和分数；点击展开短评。
- 因果说明改为可左右切换的两页，不自动轮播。
- 记忆签改为上下堆叠，每块高度150。
- 主按钮固定右下，选择未确认时禁用。

## 10. 素材

- 竹纸路径图底板。
- 四枚印章及不同覆盖程度。
- 五类失误缩略图。
- 四类记忆签和基础记忆签。
- 阿零记忆刻入动画。
- 周师傅和小满复盘姿态。

## 11. 验收

- 每轮至少出现一条动作因果和一条训练因果。
- 文案引用具体拍位或行为，不使用泛化评价。
- 候选记忆能追溯到真实行为。
- 选择记忆前无法进入下一轮。
- 玩家能说明所选记忆下一轮如何触发。
- 4/5首次玩家能说出本轮一个失误原因和一个成功原因。
- 复盘阅读不超过45秒仍可完成核心信息获取。
