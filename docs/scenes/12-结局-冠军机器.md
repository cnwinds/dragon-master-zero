# 场景12：结局——冠军机器

场景ID：`EndingScene / champion-machine`  
目标时长：35–60秒  
核心目的：让玩家感受到“技术指标和观众热度都成功，但队伍没有共同完成”  
情绪：耀眼 → 轻微不安 → 意识到胜利并不完整

## 0. 共用形象引用

- 继承最终演出的阿零、龙具、小满、队员和周师傅 `LOD-HERO` 实例。
- “冠军机器”通过继续前进、队伍脱节和聚光失衡表达，不给阿零增加红眼、黑化装甲或冠军服装。
- 第一名纹样牌是独立UI道具，不挂到角色母版上。

## 1. 进入条件

- 终局自主回望不成立。
- 观众热度不低于70。
- 队伍同心低于55。

## 2. 进入转场

继承阿零完成最高点、队伍脱节的最终姿态。

### 0–0.8秒

- 观众欢呼和灯海保持高峰。
- 摄像机继续跟随阿零落地。
- 蓝图线与阿零实际轨迹高度重合。

### 0.8–2.0秒

- 聚光灯收窄到阿零和龙头。
- 小满及后续龙身逐渐落入暗部，但仍能看见失序轮廓。
- 第一节朱砂张力线保留。

### 2.0–3.0秒

- 一枚“冠军”旧铜牌从顶部落入UI区域，不挂到阿零身上。
- 牌面只显示抽象第一名纹样和后期排版，不让图片模型生成文字。
- 标题区淡入。

## 3. 主画面构图

- 阿零位于 `x=1280 / y=650`，正面偏三分之一侧身。
- 龙头高举于 `x=1410 / y=330`。
- 聚光形成强烈金色轮廓。
- 小满位于 `x=930 / y=720`，正尝试重新整理第一节。
- 后续队员位于左侧暗部，龙身波形断开。
- 观众灯海集中在右侧，不形成完整环绕。

左侧留白：

`x=110 / y=110 / w=720 / h=760`

用于标题、评价和操作。

## 4. 重要显示元素

### 4.1 结局标题

位置：`x=128 / y=120 / w=650 / h=170`

- 主标题：`冠军机器`
- 副标题：`所有人都看见了最高点。`
- 再下一行小字：`没有人看见龙身在哪一拍断开。`

标题使用旧铜金而非朱砂，强调它确实赢得了外部成绩。

### 4.2 高光数据

位置：`x=128 / y=340 / w=650 / h=260`

显示三项：

- 最高动作高度。
- 观众热度。
- 动作完成度。

右下用较小区域显示：

- 队伍同心。
- 脱节发生拍位。

数据视觉：

- 高光项目使用旧铜刻度。
- 队伍问题使用朱砂张力线缩略，不做红色失败榜。
- 不计算总分。

### 4.3 训练报告摘要

位置：`x=128 / y=630 / w=650 / h=150`

示例：

> “阿零准确完成了前向高点。协作侧重与回望记忆不足，第一节龙身未能同步。”

必须引用本局真实原因。

### 4.4 操作区

位置：`x=128 / y=810 / w=620 / h=170`

按钮：

1. `查看脱节时刻`
2. `重演最终演出`
3. `返回首页`

## 5. 叙事动画

### 颁出结果，3–10秒

- 远处主持灯牌亮起第一名纹样。
- 人群欢呼。
- 阿零扫描观众和结果牌。
- 小满与队员在背景中把龙身重新扶正。

阿零：

> “目标高度、用时、完成率均达到最优。”

周师傅没有立即回应。

### 队伍反差，10–18秒

- 镜头保持同一方向，焦点从阿零拉到第一节龙身。
- 小满手掌因托杆拉扯轻微发红，但不做伤害特写。
- 周师傅用鼓槌敲一下绷直的龙身，发出不协调的闷响。

周师傅：

> “你赢了这一跳。还没学会带着一支龙走。”

### 阿零记录，18–25秒

- 阿零头部扫描缝从冠军牌转向龙身断点。
- 蓝图中新增一个未完成节点。
- 它没有突然道歉或表现人类悲伤，只说：

> “记录：队形未完成。”

- 标题与操作淡入。

## 6. 视觉语言

- 阿零处的蓝图和竹青轨迹高度重合，说明技术执行成功。
- 龙身后段竹青轨迹不连续。
- 第一节保留一条朱砂直线。
- 灯光只照亮龙头，龙尾逐渐变暗。
- 画面华丽度必须高于“灯散之后”，但人物关系明显失衡。

禁止：

- 把阿零画成反派。
- 使用邪恶红眼或故障特效。
- 让队员受严重伤。
- 用讽刺笑声否定玩家。

## 7. 查看脱节时刻

点击后：

- 画面回放小满受阻到阿零继续高点的5秒片段。
- 左侧显示蓝图向前、竹青跟随和第一节朱砂张力。
- 下方只显示两条原因。
- 玩家可退出回放，不改变结局。

## 8. 声音

- 欢呼和锣鼓保持真实高峰。
- 聚光缩窄时，人群高频逐渐被滤掉，只剩低频轰鸣。
- 龙身闷响必须清楚。
- 周师傅对白没有背景音乐强调。
- 标题出现时音乐保留未解决的低音，不使用失败和弦。

## 9. 手机横屏

- 阿零与小满必须同屏，禁止只展示冠军特写。
- 标题缩至左上。
- 高光数据简化为两高一低三项。
- 操作按钮横排，触控高度112。
- 查看脱节回放使用全屏，点击退出。

## 10. 素材

- 阿零高点落地与精准收势。
- 队伍晚拍、扶正龙身。
- 聚光收窄和观众高热度灯海。
- 第一名纹样牌。
- 朱砂张力缩略图。
- 脱节回放界面。
- 结局音频。

## 11. 验收

- 阿零没有完成任何完整自主回望。
- 无字幕3秒画面能同时看出“阿零耀眼”和“队伍脱节”。
- 结局文本引用实际低协作原因。
- 不把高完成度自动描述为道德失败，而是指出团队维度缺失。
- 至少4/5玩家能说明为什么它是冠军却没有出师。
- 返回首页和重演功能正常。
