# 场景11：结局——真正出师

场景ID：`EndingScene / true-apprentice`  
目标时长：45–75秒  
核心目的：确认阿零学会的不是服从某个按钮，而是在精彩与协作之间主动寻找共同节奏  
情绪：释然、温暖、克制的成就感

## 1. 进入条件

同时满足：

- 终局自主回望成立。
- 完成度不低于60。
- 队伍同心不低于65。
- 师傅信任不低于55。
- 观众热度不低于45。

## 2. 进入转场

继承最终演出的完整龙形定格。

### 0–1.4秒

- 不切黑屏。
- 竹青实际轨迹从末端开始凝固。
- 角色和龙具轮廓逐渐转为竹刻刀痕。
- 水面倒影化为第二层浅刻线。

### 1.4–2.4秒

- 背景灯火降低至70%。
- 朱砂方印“出师”从右上落到画面左下留白。
- 印章落下时产生纸面压痕，不盖住任何角色。

### 2.4秒后

- 竹刻定格重新获得极轻动态：灯火、河面、衣摆和呼吸。
- 进入可推进叙事。

## 3. 主画面构图

- 阿零位于 `x=1060 / y=650`，三分之二侧身。
- 龙头位于 `x=1210 / y=390`。
- 小满位于阿零左后方 `x=850 / y=690`。
- 后续三名队员形成向左延伸的完整龙弧。
- 周师傅位于 `x=410 / y=710`，从鼓旁走来。
- 观众和灯桥位于远景，不抢人物关系。

画面左上留出标题和印章区域：

`x=110 / y=110 / w=640 / h=300`

## 4. 重要显示元素

### 4.1 结局标题

位置：`x=128 / y=118 / w=610 / h=180`

- 主标题：`真正出师`
- 副标题：`它第一次没有照着最短的路线走。`
- 主标题字号72，副标题28。
- 朱砂方印位于主标题右下。

### 4.2 旧竹节

周师傅手中的旧竹节是结局核心道具：

- 长约阿零前臂的70%。
- 表面有真实使用磨损和旧刻线。
- 不发光，不显示数值。
- 递出时，阿零先看竹节，再看周师傅和队伍。

### 4.3 训练报告

位置：`x=1180 / y=760 / w=610 / h=190`

默认折叠，只显示一句总结：

> “你教会阿零：先确认队伍，再一起抵达高点。”

点击展开后显示：

- 最终动作谱。
- 两条记忆。
- 终局自主决策的三条主要依据。
- 四维评价。

不显示隐藏状态的原始计算过程。

### 4.4 结局操作

位置：`x=128 / y=770 / w=580 / h=220`

按钮：

1. `查看训练报告`
2. `重演最终演出`
3. `返回首页`

通关首次显示后，焦点默认在“查看训练报告”。

## 5. 叙事动画

### 周师傅走近，3–10秒

- 周师傅放下鼓槌。
- 从左侧走向阿零，步速稳定。
- 队伍保持龙具，不立刻散开。
- 小满看向阿零，轻轻调整托杆。

对白：

> 周师傅：“刚才那一拍，不在我给你的谱里。”

阿零：

> “队形发生变化。我重新计算了共同完成的路线。”

周师傅不解释主题，停顿0.6秒。

### 递出旧竹节，10–18秒

- 周师傅从龙头旧结构上取下一节磨损竹片。
- 他双手递给阿零。
- 阿零没有立即伸手，先回望小满。
- 小满点头后，阿零接过。

周师傅：

> “那就把它记在下一支龙里。”

### 队伍回应，18–26秒

- 小满把自己的托杆轻碰阿零的托杆。
- 后续队员依次轻抬龙身。
- 龙身形成一个幅度很小但连续的波。
- 不播放大规模烟花。

### 最终定格，26–32秒

- 阿零把旧竹节固定在胸前两条记忆签之间。
- 两条竹签与旧竹节形成完整结构。
- 蓝图扫描缝降低亮度。
- 竹青墨迹从队伍脚下形成完整闭环。
- 标题和操作区淡入。

## 6. 待机动画

- 河面：6秒循环。
- 灯笼：5–8秒不同相位。
- 阿零旧竹节每12秒反射一次暖光。
- 小满与队员保持轻微重心调整。
- 周师傅站在鼓旁，不循环鼓掌。

## 7. 用户交互

### 训练报告

- 点击展开为右侧大面板。
- 高亮终局时，画面同步重放3秒无UI片段。
- 再次点击收起。

### 重演

- 保留最终编排、口令和记忆。
- 从正式开场开始播放。
- 重演允许长按跳至小满受阻前。
- 重演结果必须一致。

### 返回首页

- 旧竹节和“出师”印章写入本地解锁记录。
- 首页增加极小的旧竹节装饰，但不改变菜单功能。

## 8. 声音

- 转场：竹刻刀缓慢划过与河水声结合。
- 递竹节：干燥竹材轻碰。
- 对白期间音乐极简，只保留一条低弦和远鼓余响。
- 队伍轻抬龙身时加入连续脚步和布面声。
- 标题出现使用温暖但不夸张的鼓心与锣余音。

## 9. 手机横屏

- 标题位于左上，字号64。
- 训练报告入口固定右下。
- 按钮改为横向三项，触控高度112。
- 对话字幕位于底部中央，不遮挡递竹节动作。
- 展开训练报告时暂停待机动画。

## 10. 素材

- 真正出师竹刻定格。
- 周师傅走近、取竹节、递出动画。
- 阿零观察、接取和固定竹节动画。
- 小满点头和碰杆动画。
- 训练报告展开界面。
- 首页解锁装饰。
- 结局音乐与环境声音。

## 11. 验收

- 不看对白也能看懂周师傅认可阿零成为学徒。
- 阿零接竹节前先确认小满，延续“回望”主题。
- 结局不使用奖杯、冠军榜或烟花替代情感。
- 训练报告能指出至少三条导致自主回望的玩家行为。
- 重演结果确定一致。
- 结局操作在桌面和手机横屏均可点击。
- 至少4/5玩家将该结局理解为“精彩和协作同时完成”，而不是单纯放弃高难动作。
