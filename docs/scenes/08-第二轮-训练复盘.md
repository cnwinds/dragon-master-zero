# 场景08：第二轮——训练复盘

场景ID：`ReviewScene / trial-2`  
目标时长：35–55秒  
核心目的：让玩家看清口令、第一条记忆和纠偏各自造成的影响，并选择最终演出携带的第二条记忆  
情绪：理解复杂因果 → 确认自己的训练风格 → 为最终演出负责

## 0. 共用形象引用

- 路径缩略与角色定格由第二轮演练的共用实例派生为 `LOD-THUMB`。
- 记忆签仍使用 `PROP-MEMORY-001`，只改变刻纹并安装到固定插槽。
- 复盘中的预测/实际遮罩不能改变阿零、龙头或队员轮廓。

## 1. 总体构图

复盘画面延续第一轮竹谱，但加入“预测与实际对照”：

- 左侧65%为老街三段路径。
- 右上为四维印章及第一、第二轮变化。
- 右中为口令理解。
- 底部为两条候选记忆。
- 背景保留老街末端和远处河岸灯火，暗示下一场景。

## 2. 布局

### 标题与轮次

位置：`x=96 / y=54 / w=760 / h=74`

内容：

- `第二轮复盘`
- 小字：`灯阵 · 自由口令`
- 右侧显示所用解析状态：在线、缓存或本地，不显示技术错误。

### 三段路径图

位置：`x=86 / y=142 / w=1170 / h=470`

横向划分：

1. 前灯柱。
2. 低门洞。
3. 错位灯阵。

每段显示：

- 蓝图预测线。
- 竹青实际轨迹。
- 朱砂失误。
- 竹青记忆触发。
- 纠偏鼓点位置。

底部可拖动一条对比滑杆：

- 左侧为预测。
- 右侧为实际。
- 默认停在60%实际。
- 滑杆只改变显示遮罩，不改结果。

### 四维变化

位置：`x=1300 / y=142 / w=530 / h=230`

四枚印章纵向紧凑排列，每枚显示：

- 本轮分数。
- 相比第一轮的变化箭头。
- 一条具体原因。

不使用“总分提升”标题。

示例：

- 合 74，`+16`：“回望同伴在跃前触发。”
- 稳 58，`-7`：“表现侧重使跃的制动距离增加。”

### 口令理解

位置：`x=1300 / y=396 / w=530 / h=216`

内容：

- 玩家原始口令，最多两行。
- 四项侧重刻度。
- 系统解释。
- 一条“实际证据”，点击可定位到路径拍位。

例：

> 口令强调表现，因此跃的最高点提高；稳定侧重较低，终点出现过冲。

### 因果链

位置：`x=86 / y=642 / w=1744 / h=118`

显示三段相连因果：

`玩家输入 → 阿零侧重/记忆 → 演出结果`

每段最多20字，使用蓝图、竹签、竹青轨迹三种图形连接。

至少包含：

- 一条口令因果。
- 一条记忆因果或未触发原因。
- 一条纠偏因果。

### 第二条记忆候选

位置：`x=220 / y=800 / w=1480 / h=180`

两块记忆签并排。

候选规则必须显示证据：

- 回望同伴：“你在两次高风险动作前回望。”
- 抢先争彩：“你使用两次高点动作，表现侧重65。”
- 稳住龙头：“你在稳定侧重下使用了纠偏。”
- 先探后穿：“你在穿前建立观察节点。”

候选不足时才出现“均衡起势”，并明确它是基础训练而非随机奖励。

## 3. 重要状态

### 第一条记忆已触发

- 记忆签为竹青。
- 路径图对应拍位出现同形状标记。
- 口令面板写出实际影响。

### 第一条记忆未触发

- 记忆签为雾灰，不标红。
- 文案：“本轮没有在穿前使用探或回望，因此未触发。”
- 不扣额外分数。
- 玩家仍可在最终编排中重新满足条件。

### 在线解析降级

- 复盘只显示最终使用的侧重和“本地理解”。
- 不向玩家展示失败堆栈。
- AI使用台账可在开发日志记录错误类型，但不显示原始口令。

## 4. 进入动画

总时长1500毫秒：

1. 老街实际轨迹压平为三段路径图，500毫秒。
2. 预测线从路径下方显现，300毫秒。
3. 四枚印章落下，400毫秒。
4. 因果链从左向右连接，300毫秒。
5. 记忆候选在最后开放交互。

点击可跳过动画。

## 5. 记忆选择

交互沿用第一轮，但增加“与第一条记忆组合”预览。

聚焦第二条记忆时，右侧显示：

- 第一条记忆。
- 当前候选。
- 两者是否互补或放大同一倾向。
- 最终演出可能触发的动作条件。

示例：

- `先探后穿 + 回望同伴`：提高观察与协作，表现需要由口令补足。
- `抢先争彩 + 稳住龙头`：高点更大胆，纠偏后的恢复更快。

不显示“推荐最佳组合”，避免替玩家作价值选择。

确认后：

- 第二条竹签进入阿零胸腔。
- 两条记忆以一上一下的细竹片显示。
- 周师傅只说：“最后一轮，不再给它答案。”

## 6. 进入最终演出

确认记忆后，背景远处河岸灯火亮起。

按钮：

- 主按钮：`前往主舞台`
- 次按钮：`重看灯阵`
- 辅助入口：`查看两条记忆`

点击主按钮：

- 三段老街路径折叠为一条竹简。
- 两条记忆签固定在阿零胸前。
- 水墨从窄街向两侧打开，转入河岸宽景。

## 7. 声音

- 路径图铺开声比第一轮更厚。
- 预测/实际滑杆移动时分别使用机械细响和竹片摩擦声。
- 因果链连接依次发出蓝图脉冲、竹刻刀、低鼓声。
- 记忆组合预览为两片竹片轻碰。
- 进入主舞台时远处锣鼓和人群声逐渐增强。

## 8. 手机横屏

- 路径图占上半屏，可横向滑动三段。
- 四维变化和口令理解放入右侧可切换标签。
- 因果链改为纵向三步。
- 两条候选记忆上下排列。
- 第一条记忆常驻左上，第二条选择后并列。
- 主按钮固定右下安全区。

## 9. 素材

- 三段路径复盘图。
- 预测/实际对比滑杆。
- 四维变化印章。
- 在线、缓存、本地解析状态。
- 因果链三类节点。
- 记忆组合预览。
- 河岸灯火过渡背景。

## 10. 验收

- 复盘至少明确展示口令、记忆、纠偏三类因果。
- 记忆未触发时显示具体原因且不伪造收益。
- 候选记忆符合GDD中的生成条件。
- 三条标准路径能稳定生成所需候选。
- 玩家选择第二条记忆前无法进入主舞台。
- 至少4/5玩家能根据复盘说出最终演出想保留或改变的一项策略。
- 界面不暴露隐藏状态精确数值或结局概率。
