# 场景04：第一轮——基础演练

场景ID：`PerformanceScene / trial-1`  
目标时长：20–35秒  
核心目的：第一次让玩家看懂“蓝图预测、竹青实际、朱砂错误”和鼓点纠偏  
情绪：期待 → 发现差异 → 成功参与修正

## 0. 共用形象引用

- 阿零、竹青舞龙、小满、队员、周师傅和旧鼓与第一轮编舞使用同一批 `LOD-GAMEPLAY` 实例。
- 演练只改变动作状态、张力、轨迹和镜头，不重新生成角色或龙具。
- 龙头固定缺口、四段修补标记和队员顺序必须在运动中保持可追踪。

## 1. 进入状态

继承：

- 玩家八拍动作序列。
- 示范口令解析后的四项侧重。
- 第一轮关卡目标。

场景进入后动作序列锁定，不能中途重新编排。

## 2. 画面布局

### 演出舞台

位置：`x=72 / y=52 / w=1776 / h=790`

- 竹棚训练场扩展到全宽。
- 阿零起点位于 `x=520 / y=690`。
- 两根训练灯柱位于 `x=940` 与 `x=1260`。
- 周师傅和鼓位于右后方。
- 小满与后续龙身始终在阿零后方可见。

### 精简时间轴

位置：`x=180 / y=866 / w=1390 / h=130`  
层级：`z=300`

- 八拍横向排列。
- 当前拍宽度提升8%，其他拍保持不动。
- 已完成拍位压成竹刻深纹。
- 未执行拍位保留蓝图虚线。
- 风险拍位顶部出现旧铜小缺口。

### 纠偏鼓面

位置：`x=1610 / y=850 / w=210 / h=170`  
层级：`z=330`

构成：

- 鼓面直径132。
- 上方显示两枚朱砂圆形令牌。
- 下方只在窗口出现时显示“空格 / 轻触”。
- 非窗口期透明度55%，不可误触消耗。

### 侧重摘要

位置：`x=86 / y=82 / w=360 / h=112`

- 四个细刻度横排，不显示大面积雷达图。
- 当前最高侧重使用对应图形强调。
- 8秒后自动淡至40%，避免干扰演出。

### 目标状态

位置：`x=1420 / y=82 / w=400 / h=110`

- “穿过灯柱”
- “完成一次回望”

状态以小图标显示未完成、完成或受损，不显示总分。

## 3. 演出节拍

八个编舞拍每拍基准1.25秒。双拍动作占2.5秒。场景含3秒准备和3秒收束，总演出约16秒；若出现纠偏停顿，总时长可到20秒。

### 准备，0–3秒

- 左右编舞面板退出后，时间轴落到底部。
- 摄像机从训练桌位置推到舞台全景。
- 蓝图预测轨迹按玩家序列完整绘制，但透明度只有38%。
- 周师傅抬起鼓槌。
- 文字：“训练不是接管。看它怎么理解。”

### 拍1–2

- 阿零执行第一组动作。
- 预测线先于动作150毫秒亮起。
- 实际竹青轨迹紧随龙头。
- 当前拍位与鼓声同步点亮。
- 如果玩家使用“探→穿”，灯柱间路径显示竹青细桥。

### 拍3–4

- 引入第一次可理解偏差。
- 若节奏侧重较低，实际轨迹相对时间轴轻微迟后。
- 若稳定较低，龙头在动作终点产生8–18像素过冲。
- 差异必须可见但不造成严重失败。

### 第一次纠偏窗口

触发：第一处中等以上风险动作前0.65秒。

表现：

- 鼓面从55%提升至100%。
- 朱砂圆环由直径188收束至132。
- 当前拍位出现同心圆。
- 周师傅不说话，只抬眼。

结果：

- 正拍：实际轨迹在下一动作前收回蓝图范围。
- 近拍：只修正约50%偏差。
- 错拍：下一动作起势增加轻微迟疑。
- 不操作：按原风险继续。

### 拍5–7

- 镜头水平跟随阿零穿过灯柱。
- 小满与后续队员的动作延迟沿龙身传递。
- 使用“回望”时，阿零头、躯干和龙头依次回转，但幅度小于终局回望。
- 队伍间距在回望后恢复，显示“合”图标短暂亮起。

### 第二次纠偏窗口

触发：

- 若仍有令牌，在最后一个风险动作前出现。
- 若没有明显风险，在第7拍提供一次可选节奏强化窗口。

该窗口不强制玩家使用，结束后令牌不兑换额外分数。

### 拍8与收束

- 最后动作完成后，阿零和队伍回到稳定姿态。
- 蓝图预测线淡至15%，竹青实际线保留0.9秒。
- 两根灯柱根据结果保持稳定或轻微摆动。
- 摄像机停留1.2秒，随后进入轨迹压平转场。

## 4. 五类失误显示

本轮最多出现两类失误，避免教学过载。

### 抢拍

- 当前动作提前于拍点。
- 实际轨迹开头越过时间轴垂直刻线。
- 显示短标签：“抢拍 · 表现侧重过高”。

### 迟疑

- 起势前出现深色墨点。
- 阿零关节停顿150–300毫秒。
- 显示：“迟疑 · 节奏侧重不足”。

### 过冲

- 竹青轨迹越过蓝图终点。
- 终点出现朱砂折返箭头。
- 显示：“过冲 · 稳定不足”。

### 脱节

- 阿零与小满之间出现朱砂张力线。
- 小满步幅被迫拉大。
- 显示：“脱节 · 未确认队形”。

### 触灯

- 仅在严重路径错误时出现。
- 灯笼摆动，接触点出现交叉刻痕。
- 不播放夸张爆炸或碎裂。

## 5. 重要动画

### 预测与实际双轨

- 蓝图线总是先出现。
- 竹青线永远附着于实际龙头位置生成。
- 两线完全一致时，竹青线覆盖蓝线但蓝色边缘仍露出2像素。
- 两线偏离时，不使用箭头解释全过程，让玩家先观察，再由复盘说明。

### 龙身传导

- 龙头动作后80毫秒影响第一节。
- 后续每节再延迟80–140毫秒。
- 良好协作时波形连续。
- 脱节时第一节先绷直，末段随后失去节奏。

### 镜头反馈

- 正拍纠偏：镜头向动作方向移动6像素后回正。
- 过冲：镜头不跟随越界部分，强化“超出控制”。
- 禁止大幅震屏。

## 6. 用户交互

演出中只允许：

- 空格或点击鼓面进行纠偏。
- Escape暂停。
- 点击右上声音按钮。

不允许：

- 点击阿零改变动作。
- 拖动时间轴。
- 点击预测路线改变方向。
- 在演出过程中修改训练口令。

纠偏窗口外按空格：

- 不消耗令牌。
- 鼓面轻微震动并显示“等待鼓点”，持续0.5秒。

## 7. 声音

- 八拍鼓点保持清晰，第一拍重、第五拍次重。
- 蓝图预测线使用极轻的机械脉冲，不覆盖鼓声。
- 竹青实际轨迹配合竹杆划风声。
- 正拍为鼓心，近拍为鼓边，错拍为闷鼓。
- 回望动作减少背景机械声，突出龙身布料和脚步重新同步。

## 8. 转入复盘

演出结束1.2秒后：

1. 摄像机停止。
2. 角色和背景降低至28%饱和度。
3. 竹青实际轨迹保持，蓝图线淡出。
4. 实际轨迹从右向左压平为一张竹刻路径图。
5. 时间轴随路径图折叠进入复盘界面。

转场时长900毫秒。

## 9. 手机横屏

- 时间轴缩为 `x=170 / y=820 / w=1280 / h=140`。
- 纠偏鼓面扩大到 `240×200`，固定右下。
- 侧重摘要只显示最高和最低两项。
- 目标状态移动到左上。
- 演出期间屏蔽页面滚动和浏览器双击缩放。
- 触觉反馈只在正拍和严重失误时触发。

## 10. 素材

- 四种动作完整骨骼动画。
- 五种失误覆盖动画。
- 两根灯柱摆动。
- 蓝图和竹青轨迹着色器。
- 朱砂张力线与接触刻痕。
- 精简时间轴与鼓面全部状态。
- 第一轮鼓点、角色脚步、竹杆和龙身声音。

## 11. 验收

- 玩家无需查看复盘就能注意到预测和实际轨迹可能不同。
- 至少4/5玩家能指出一次具体失误发生在哪里。
- 纠偏窗口外操作不消耗令牌。
- 已完成动作不因后续纠偏改变。
- 回望影响整支队伍，不只是阿零头部旋转。
- 演出画面始终能看到阿零和小满的关系。
- 静音状态下仍可依靠圆环完成纠偏。
- 兼容品质下保持30 FPS以上。
