# 场景01：首页

场景ID：`TitleScene`  
逻辑尺寸：1920×1080  
目标停留：5–30秒  
核心目的：用一张画面交代“机器人、舞龙、江南灯会、传统与技术融合”，同时提供清晰入口  
情绪：庄重、神秘、演出开始前的克制期待

## 1. 进入条件

- 游戏资源加载完成。
- 首次启动、结局返回或暂停菜单返回首页。
- 若存在存档，首页显示“继续训练”；否则只显示“开始训练”。

## 2. 总体构图

画面采用左静右动的不对称构图：

- 左侧35%为标题和菜单留白。
- 中右区域为阿零、龙头和舞龙队。
- 上方龙身形成从右上向中间回落的弧线，阻止视线飞出画面。
- 河面倒影把右侧视觉重量带回下方。
- 不展示终局完整回望；阿零身体始终朝向主舞台。

镜头：

- 35毫米等效广角。
- 机位高度约1.25米，略低于阿零胸口。
- 摄像机朝右前方舞台偏转8度。
- 景深焦点位于阿零和龙头，左侧留白保持清晰，远景轻微虚化。

## 3. 场景分层

### 远景 `z=0–49`

- 深夜靛青天空，顶部颜色从`#0A1018`过渡到`#121D2C`。
- 水墨云气从右上向左中缓慢扩散。
- 江南屋檐和拱桥位于地平线 `y=410–560`，只保留剪影和少量暖窗。
- 远处灯会人群为低细节墨点，不出现可辨识面孔。

### 中景 `z=50–159`

- 河岸舞台位于 `x=1040–1920 / y=510–870`。
- 旧铜灯笼沿右侧纵深排列，最近一盏位于 `x=1740 / y=260`。
- 周师傅站在 `x=960 / y=610`，身旁旧鼓位于 `x=895 / y=665`。
- 小满与三名队员从 `x=1330` 延伸至 `x=1790`，托起四段龙身。

### 主体 `z=160–219`

- 阿零脚底中心：`x=1370 / y=890`。
- 阿零显示高度：约590像素。
- 龙头中心：`x=1490 / y=505`，宽约300像素。
- 托杆从阿零双手延伸至龙头下方，必须显示真实受力关系。
- 阿零身体朝右前方，头部扫描缝可短暂向后扫，但躯干不回转。

### 效果 `z=220–269`

- 阿零关节周围出现三组低透明度蓝图圆弧。
- 一条预测虚线从龙头延伸向右上舞台高点，长度不超过420像素。
- 不显示竹青实际轨迹，暗示演出尚未开始。

## 4. 重要显示元素

### 4.1 游戏标题

元素ID：`title-logo`  
位置：`x=128 / y=116 / w=660 / h=220`  
层级：`z=310`

构成：

- 主标题“龙师零号”占两行或一行横排，以实际标题字设计为准。
- “龙师”使用思源宋体重字重，局部笔画带竹刻缺口。
- “零号”使用蓝图几何辅助线，但最终字形仍清晰。
- 标题右下放置一枚空白朱砂方印轮廓，内部后期写“零”，不由图片模型生成。
- 英文标题 `DRAGON MASTER ZERO` 位于主标题下方，字号24，字距0.18em。

标题背景：

- 保持低对比水墨留白。
- 不放灯笼、角色脸部、强反射或蓝图参数。

### 4.2 主菜单

元素ID：`main-menu`  
位置：`x=150 / y=505 / w=420 / h=300`  
层级：`z=310`

按钮顺序：

1. `继续训练`：仅有存档时显示。
2. `开始训练`：有存档时改为“重新开始”并要求确认。
3. `设置`
4. `制作名单`

按钮规格：

- 单项高度64，垂直间距18。
- 文字左对齐。
- 默认无实体按钮框，只显示文字和左侧短刻线。
- 聚焦时旧铜刻线从24像素延伸至86像素，持续180毫秒。
- 当前项文字由米白变为旧铜金。
- 点击时标题画面不瞬间消失，先完成声音与蓝图转场。

### 4.3 存档摘要

元素ID：`save-summary`  
位置：`x=150 / y=830 / w=520 / h=86`  
层级：`z=305`

仅在存在存档时显示：

- 第一行：最近阶段，例如“第二轮 · 灯阵编舞”。
- 第二行：最近保存时间和离线/在线状态，不显示原始口令。
- 使用24号思源黑体，透明度72%。
- 不使用卡片容器，只在左侧显示一条竹青细线。

### 4.4 系统入口

元素ID：`utility-actions`  
位置：`x=1610 / y=56 / w=238 / h=54`  
层级：`z=320`

包含：

- 声音开关。
- 全屏切换，仅桌面显示。
- 当前解析状态小点：首页只显示“本地可用”，不主动联网。

图标使用原创线性图标，点击区域不小于64×54。

### 4.5 版本与版权信息

元素ID：`version-info`  
位置：`x=128 / y=1000 / w=900 / h=32`  
层级：`z=300`

内容：

- Demo版本号。
- “原创游戏画面，文化元素为艺术化设计”。
- 字号20，透明度55%。

## 5. 首次进入动画

总时长：2800毫秒。

### 0–450毫秒

- 画面从深墨淡入。
- 先出现水面和远景灯火，不出现UI。
- 一声远鼓建立空间。

### 450–1050毫秒

- 龙头从右侧轻微进入稳定位置，龙身随惯性摆动。
- 阿零关节由下至上依次亮起低亮度蓝图环。
- 摄像机从原位置向前推近1.8%。

### 1050–1650毫秒

- 蓝图预测线从阿零手部沿托杆绘制到龙头，再指向舞台高点。
- 阿零头部扫描缝亮起并扫过45度，不转动躯干。

### 1650–2200毫秒

- 标题以竹刻刀痕由左向右显现。
- 朱砂方印在末尾落下，伴随轻微纸张压痕。

### 2200–2800毫秒

- 菜单逐项从下方12像素淡入。
- 首个可用按钮自动获得键盘焦点。
- 此时才允许交互，之前的点击只触发“跳过开场动画”。

## 6. 待机动画

循环周期不完全同步，避免机械重复：

- 河面波纹：6.4秒循环。
- 远雾：11秒缓慢漂移。
- 灯笼风摆：每盏4.8–7.2秒随机周期，角度不超过3度。
- 龙身呼吸式起伏：5.6秒，幅度8–14像素。
- 阿零待机：基本静止，每9–14秒进行一次头部环境扫描。
- 小满调整握杆：12–18秒一次，不与阿零扫描同步。
- 蓝图预测线每6秒出现一次非常轻的流动刻度。

待机画面不得让阿零完整回头。

## 7. 用户交互

### 鼠标

- 移入菜单项触发刻线延展和竹片擦声。
- 点击“开始训练”进入序章。
- 点击“重新开始”弹出确认层。
- 8秒无操作后，菜单亮度下降8%，场景动画继续。

### 键盘

- 上下方向键切换菜单。
- Enter确认。
- Escape在首页无动作。
- 任意键可跳过首次进入动画。

### 触控

- 单击菜单直接确认，不要求双击。
- 首次触摸页面时初始化音频。
- 超宽手机中菜单保持在16:9安全区，不移动到刘海区域。

## 8. 退出动画

点击“开始训练”后：

1. 菜单在220毫秒内向左淡出。
2. 标题竹刻线转为蓝图辅助线。
3. 蓝图线沿龙头托杆向右移动。
4. 摄像机跟随蓝线进入河岸舞台。
5. 900毫秒后无缝衔接序章第一帧。

点击“继续训练”时：

- 标题化为水墨，使用对应地点的主色完成转场。
- 不重复播放序章。

## 9. 声音

- 环境底：远处人群、河水、灯笼纸张和低风。
- 音乐：低音鼓心每8秒一次，加入极轻竹箫气声，不形成完整旋律。
- 标题落印：纸张压印加低频鼓声。
- 菜单聚焦：竹片轻擦。
- 确认：短木击与低音机械脉冲叠加。

## 10. 手机横屏调整

- 标题缩至 `x=190 / y=80 / w=720 / h=190`。
- 菜单改为底部横排抽屉：`x=180 / y=760 / w=1560 / h=230`。
- 只显示三个主要入口；制作名单放入设置。
- 阿零向右移动90像素，避免与标题重叠。
- 存档摘要缩为一行，放在菜单上方。
- 触控按钮高度不低于112逻辑像素。

## 11. 素材清单

- 6层首页背景。
- 阿零首页待机骨骼动画。
- 龙头和四段龙身。
- 小满、周师傅及三名队员剪影。
- 灯笼近中远三套。
- 水面反射与雾层。
- 标题字、朱砂印章和菜单图标。
- 首页环境音和UI声音。

## 12. 验收

- 缩至320×180后仍可辨认“机器人舞龙”。
- 左侧标题区不存在强灯、角色脸或高频纹理。
- 首次进入动画不超过2.8秒，可一键跳过。
- 阿零待机不展示完整回望。
- 有无存档时菜单项和焦点顺序正确。
- 鼠标、键盘和触控均能进入游戏。
- 1366×768、1920×1080、844×390和932×430下无关键遮挡。
- 首页连续运行10分钟无明显动画跳变、内存增长或音频叠加。
