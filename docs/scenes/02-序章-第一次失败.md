# 场景02：序章——第一次失败

场景ID：`PrologueScene`  
目标时长：75–90秒  
核心目的：用一次可参与的失败说明“动作正确不等于舞龙正确”  
情绪：期待 → 短暂兴奋 → 意外失序 → 产生训练动机

## 1. 进入与退出

进入：

- 首页选择“开始训练”。
- 首页蓝图线沿托杆完成转场后直接进入，不黑屏。

退出：

- 周师傅说出“先教它看见身后的人”。
- 玩家确认后进入第一轮竹棚编舞。

## 2. 空间

地点：竹棚训练场外侧的试演空地。  
时间：灯会前一日傍晚。  
天气：无雨，空气湿润，远处有薄雾。

构图：

- 主舞台区域：`x=120 / y=80 / w=1680 / h=800`。
- 阿零起点：`x=570 / y=760`。
- 小满及队伍向左后方延伸至 `x=210`。
- 目标高点位于 `x=1470 / y=300`。
- 周师傅与鼓位于 `x=1540 / y=700`。
- 底部交互区：`x=240 / y=865 / w=1440 / h=150`。

镜头为侧前方广角，确保阿零、第一节龙身、小满和目标高点同时可见。

## 3. 场景画面

### 背景

- 天空为宣纸米白向灰青过渡，远处屋顶由淡墨构成。
- 竹棚柱子位于左右边缘，形成天然画框。
- 地面为湿润夯土，保留少量灯架倒影。
- 训练用灯柱只有两根，避免序章信息过多。

### 角色

- 阿零处于完美直立待机，双手握龙头杆。
- 小满站在其后第一节，主动观察阿零。
- 三名队员依次降低对比度。
- 周师傅右手持鼓槌，左手按住鼓面。

### 预测信息

- 蓝图线从阿零脚下连接至目标高点。
- 路径是过于直接的高抛线，没有任何回望节点。
- 阿零头部扫描只覆盖前方120度。
- 蓝线旁显示三个短标签：“速度”“高度”“终点”，不显示复杂参数。

## 4. 重要显示元素

### 4.1 章节标题

位置：`x=128 / y=72 / w=680 / h=90`  
内容：`序章 · 它只会完成任务`

- 字号44。
- 出现2.2秒后淡至35%透明度。
- 不使用全屏章节卡，保持场景连续。

### 4.2 开始鼓面

位置：`x=760 / y=875 / w=400 / h=112`  
层级：`z=320`

内容：

- 中央圆形鼓面直径112。
- 左侧文字：“敲下第一拍”。
- PC提示：空格。
- 触控提示：轻触鼓面。

鼓面每1.6秒出现一次由外向内的旧铜金收束圈，不判定节奏，只等待玩家主动开始。

### 4.3 跳过

位置：`x=1650 / y=990 / w=170 / h=38`

- 在进入3秒后出现。
- 长按或按住Escape 0.8秒跳过。
- 跳过后仍播放8秒精简失败片段，不能完全绕过核心冲突。

### 4.4 对话字幕

位置根据说话者变化：

- 周师傅：`x=1130 / y=735 / w=570 / h=120`。
- 小满：`x=290 / y=650 / w=560 / h=120`。
- 阿零：`x=650 / y=560 / w=520 / h=105`。

对话框使用半透明水墨底，不遮挡龙身托杆。

## 5. 动画时间线

### 阶段A：建立期待，0–12秒

0–3秒：

- 首页镜头继续向前移动，落到试演空地。
- 标题淡入。
- 阿零扫描目标高点。

3–7秒：

- 小满：“第一次完整试演，跟着鼓走。”
- 阿零：“目标已确认。用时优先。”
- “用时优先”四字以蓝图小标签出现在阿零肩侧。

7秒后：

- 开始鼓面出现。
- 场景进入可交互等待。

### 阶段B：玩家启动，12–17秒

玩家敲击后：

- 鼓面下压6像素，120毫秒回弹。
- 周师傅同步敲鼓。
- 蓝图路线由30%提升至72%透明度。
- HUD缩至底部细时间轴，只显示8个拍点。

### 阶段C：机械式成功，17–29秒

- 拍1–2：阿零精确完成前探和抬升，轨迹完全贴合蓝线。
- 拍3–4：龙头快速升高，观众远景传来一声惊叹。
- 阿零动作保持机械直线，小满开始被迫加大步幅。
- 第一节龙身张力逐渐拉直，但画面暂不标红。

镜头：

- 从全景缓慢推到阿零和小满的双人中景。
- 不切镜，确保因果连续。

### 阶段D：失败，29–39秒

- 拍5：阿零继续向前高跃。
- 小满脚步跟不上，第一节龙身完全绷直。
- 蓝图线仍显示“动作完成率100%”。
- 竹青实际轨迹在阿零处正确，却在小满处断裂。
- 小满向前踉跄，后续龙身依次失序。
- 训练灯柱被龙身尾段碰歪，但不夸张倒塌。

关键停顿：

- 小满失去重心后冻结0.22秒。
- 朱砂张力线从阿零延伸至小满。
- 鼓声突然停止，只保留竹架晃动声。

### 阶段E：理解问题，39–66秒

39–47秒：

- 阿零头部扫描缝回扫，但身体和龙头仍朝前。
- 阿零：“动作序列已全部完成。”
- 画面左下短暂显示：“动作完成：100% / 队形完成：31%”。

47–58秒：

- 周师傅走近，不责骂阿零。
- 他用鼓槌点一下绷直的龙身：“龙头不是终点。后面还有人。”
- 蓝图路线向后扩展，第一次把小满与队伍纳入测量范围。

58–66秒：

- 周师傅：“先别教它更快。先教它看见身后的人。”
- 阿零头部扫描小满，只转头，不做完整回望。

### 阶段F：交付玩家，66–90秒

- 屏幕中央出现一张动作竹简“回望”，由周师傅放到训练桌。
- 竹简落下时没有教程弹窗，只显示一句：“动作可以记录，分寸需要训练。”
- 玩家点击“开始训练”进入下一场景。

## 6. 用户交互

必需交互：

- 敲下第一拍。
- 推进三段关键对话。
- 点击“开始训练”。

可选交互：

- 在失败冻结时移动鼠标或触摸阿零、小满、蓝图路线，显示一句观察说明。
- 观察说明只出现一次，不阻断时间线。

禁止：

- 玩家不能在序章纠偏。
- 玩家不能改变失败结果。
- 不出现“你失败了”或重试按钮。

## 7. 声音

- 开场：远风、竹棚轻响、低频环境。
- 玩家起拍：第一声鼓必须饱满，成为游戏的声音标志。
- 机械式成功：鼓点精确但偏冷，加入低机械节拍。
- 龙身绷紧：竹纤维受力、布面摩擦。
- 失败停顿：完全停止音乐0.8秒。
- 周师傅对白后：加入一声较轻的鼓边音，引导训练。

## 8. 手机横屏

- 章节标题缩至左上 `x=170 / y=70 / w=780`。
- 开始鼓面放大为 `480×132`，位于底部中央。
- 对话文字不超过两行，每行不超过17字。
- 可观察热点关闭悬停，改为轻触。
- 跳过按钮位于右上安全区。

## 9. 重要资产

- 试演空地背景6层。
- 阿零前向高跃动画。
- 小满踉跄、恢复和观察动画。
- 四段龙身由有序到失序的传导动画。
- 训练灯柱碰撞动画。
- 蓝图前向路线和扩展队伍路线。
- 朱砂张力线。
- 周师傅敲鼓、走近和点龙身动画。

## 10. 验收

- 不看字幕也能通过龙身张力看懂阿零拖累队伍。
- 蓝图显示“动作完成”与队形失败形成明确反差。
- 开场扫描只转头，不展示终局完整回望。
- 玩家在进入90秒内必然到达第一轮编舞。
- 跳过后仍能理解训练动机。
- 至少4/5名首次玩家能回答：“阿零的问题不是动作不会，而是不看队友。”
