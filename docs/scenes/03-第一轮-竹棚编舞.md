# 场景03：第一轮——竹棚编舞

场景ID：`TrainingScene / trial-1`  
目标时长：90–120秒  
核心目的：让玩家在无外部说明下理解八拍编排、动作衔接和示范口令  
情绪：安全、专注、第一次拥有训练权

## 1. 场景目标

硬目标：

- 填满八拍。
- 通过两根训练灯柱。

软目标：

- 至少安排一次“回望”。

本轮可用动作：

- 探
- 穿
- 盘
- 回望

本轮口令采用示范选择，不开放自由输入。

## 2. 桌面布局

### 顶部目标条

位置：`x=390 / y=38 / w=1100 / h=76`  
层级：`z=290`

内容：

- 左侧章节：`第一轮 · 听见鼓点`
- 中部硬目标：灯柱图标 + “安全穿过”
- 右侧软目标：回望图标 + “至少回望一次”
- 最右显示当前拍数：`0 / 8`

目标条使用透明底，不做整块卡片；信息落在一条横向竹刻标尺上。

### 左侧动作栏

位置：`x=72 / y=145 / w=292 / h=720`  
层级：`z=300`

结构：

- 标题“动作竹简”，高度54。
- 四张动作竹简纵向排列。
- 每张尺寸 `248×92`，间距18。
- 下方保留 `248×138` 动作说明区。

动作说明区显示：

- 动作名和拍数。
- 一句用途。
- 当前场景中的风险。
- 6帧小型轨迹预览。

### 中央预演区

位置：`x=390 / y=132 / w=1090 / h=562`  
层级：`z=100–269`

画面：

- 竹棚训练场占满区域。

- 两根训练灯柱位于局部坐标 `x=560` 和 `x=930`。
- 周师傅站在右后方鼓旁。

预演区不是视频窗口，不画明显边框。边缘通过水墨淡出融入背景。

### 右侧训练面板

位置：`x=1505 / y=132 / w=343 / h=562`  
层级：`z=310`

分为三段：

1. 师傅提示：`h=145`
2. 训练口令：`h=250`
3. 预计侧重：`h=167`

初始只展开师傅提示：

> “先让龙头知道什么时候该看路，什么时候该看人。”

时间轴填满后自动展开示范口令。

### 八拍时间轴

位置：`x=390 / y=735 / w=1100 / h=186`  
层级：`z=320`

结构：

- 8个拍位横向排列。
- 单格尺寸 `122×112`，间距12。
- 第一拍左侧附鼓槌起点图形。
- 每格顶部显示拍号，底部显示衔接状态。
- 双拍动作占据两个拍位，中间以连续竹纹连接。

状态：

- 空：低透明度米白槽。
- 可落：竹青内发光。
- 非法：朱砂交叉刻痕。
- 良好衔接：两格之间出现竹青细桥。
- 风险衔接：两格之间出现旧铜断口。
- 已锁定：竹纹压实，不能拖动。

### 底部操作区

位置：`x=1505 / y=735 / w=343 / h=186`

包含：

- `清空`：次按钮。
- `自动补全`：教学辅助，仅第一轮出现。
- `开始演练`：主按钮，尺寸 `300×76`。

时间轴未填满时，开始按钮显示“还差N拍”，不可点击。

## 3. 场景背景与光影

- 时间为日暮前，整体偏宣纸米白和灰青。
- 竹棚顶部投下规则斜影，暗示节拍格。
- 两根灯柱使用低饱和旧铜色，不抢主体。
- 阿零受到左上冷天光和右侧鼓旁暖光。
- 蓝图信息在浅背景上增加深靛半透明底线，保证可读。

视差层：

1. 远山与屋檐，移动幅度0.3%。
2. 竹棚后墙，0.6%。
3. 悬挂旧龙头与训练布，1.0%。
4. 角色和灯柱，固定。
5. 前景竹叶，1.4%，只占边角。

## 4. 首次教学流程

教学不使用一张覆盖全屏的说明图，而是逐步开放交互。

### 步骤1：放置“探”

- 动作栏仅“探”保持100%亮度。
- 第一拍出现竹青呼吸高亮。
- 文案：“先看清前路。”
- 玩家可以拖放或依次点击动作与拍位。
- 放置后，中央阿零播放0.8秒低速前探预演。

### 步骤2：接入“穿”

- 第二拍高亮。
- “穿”竹简出现一条连接第一拍的竹青细线。
- 文案：“被观察过的路，更容易穿过。”
- 放置后，两根灯柱之间显示预测虚线。

### 步骤3：自由填充

- 解锁盘与回望。
- 屏幕不再指定唯一槽位。
- 目标条提醒“至少回望一次”。
- 若玩家20秒无操作，周师傅提示一次：“双拍动作需要两个空位。”

### 步骤4：处理非法放置

首次尝试把“盘”放到第8拍时：

- 第8拍显示朱砂交叉刻痕。
- 竹简返回动作栏。
- 文案：“盘需要连续两个空拍。”
- 只触发一次详细说明，后续使用短提示。

### 步骤5：示范口令

时间轴填满后，右侧训练口令展开三项：

1. “先稳住龙头，多看后面的队友。”
2. “跟紧鼓点，动作保持连贯。”
3. “按照均衡方式完成训练。”

玩家选择其一。选择后：

- 口令文字被蓝图扫描线扫过。
- 四项侧重用四条同长起始刻度动画到目标值。
- 展示一句理解结果。
- 不显示精确算法说明。

## 5. 动作预演

### 单动作预演

鼠标悬停或长按动作时：

- 中央场景暂停环境人物的非必要动作。
- 阿零以35%速度播放起势、主动作、收势。
- 蓝图线先绘制，竹青线后跟随。
- 预演不影响已编排内容。

### 整段幽灵预演

时间轴填满后：

- 场景中出现透明度28%的阿零幽灵姿态序列。
- 每个关键姿态对应一个拍位。
- 风险衔接处显示旧铜刻线，不显示最终是否失误。
- 玩家修改任一动作后，预演在120毫秒内刷新。

## 6. 用户交互

### 放置

- 拖放：竹简中心越过槽位50%即吸附。
- 点击：先选竹简，再选起始拍位。
- 双拍动作自动占据下一拍。
- 点击已放动作可选中，再点击空槽移动。
- 拖出时间轴或按Delete移除。

### 重排

- 拖动已放动作时，原槽显示半透明占位。
- 合法新位置显示竹青。
- 不允许自动挤开其他动作，避免不可预测重排。

### 详情

- 右键、长按或点击动作栏下方“详情”显示完整说明。
- 详情浮层不超过中央场景的30%。

### 开始演练

按钮可用条件：

- 八拍填满。
- 已选择示范口令。
- 不存在越界或重叠。

点击后先显示2秒确认摘要：

- 动作序列。
- 主要训练侧重。
- 一个最高风险点。

玩家可返回修改或确认开始。

## 7. 动画

### 场景进入

总时长900毫秒：

- 序章中的“回望”竹简落入左侧动作栏。
- 其余三张竹简沿竹纹依次展开。
- 时间轴由鼓声从左至右敲出8个拍位。
- 四区UI最后淡入。

### 交互反馈

- 竹简拾取：上浮8像素，120毫秒。
- 吸附槽位：160毫秒弹性，但回弹幅度不超过4像素。
- 良好衔接：竹青细桥在240毫秒内生长。
- 风险衔接：旧铜断口闪一次，不持续呼吸。
- 口令解析：蓝图扫描350毫秒，侧重刻度420毫秒。

### 退出

- 动作竹简压入时间轴，形成一条横向竹刻谱。
- 左右面板向外退出。
- 中央预演区扩展到全屏演练构图。
- 转场650毫秒。

## 8. 声音

- 每个拍位生成时对应一声很轻的鼓边音。
- 放置单拍动作：短竹击。
- 放置双拍动作：一短一长两次竹击。
- 良好衔接：柔和木滑音。
- 风险衔接：旧铜轻碰。
- 非法操作：竹节闷响。
- 口令解析：低机械脉冲沿四项侧重移动。

## 9. 手机横屏

布局改变：

- 顶部目标条保留。
- 中央预演区：`x=160 / y=95 / w=1600 / h=520`。
- 动作栏改为底部抽屉，展开高度360。
- 八拍时间轴位于 `x=180 / y=650 / w=1560 / h=190`。
- 右侧口令面板改为点击“训练口令”后打开的半屏浮层。
- 主按钮固定在右下安全区，尺寸 `300×112`。

触控操作：

- 默认使用点选动作—点选槽位。
- 长按显示预演。
- 时间轴支持水平轻扫，但开始按钮不可随内容滚走。

## 10. 重要资产

- 竹棚训练场分层背景。
- 四种动作竹简及状态图。
- 八拍槽位九种状态。
- 阿零四种动作预演。
- 两根训练灯柱。
- 三条示范口令及侧重结果。
- 良好/风险衔接图形。
- 教学高亮和确认摘要。

## 11. 验收

- 4/5首次玩家在120秒内完成合法编排。
- 玩家能说明“动作决定做什么，口令决定怎么做”。
- 双拍动作无法越界或重叠。
- 任一非法操作都有具体文字原因。
- 同一动作的拖放与点击放置结果一致。
- 时间轴填满前不能误入演练。
- 低分辨率下目标、时间轴和开始按钮同时可见。
- 整个界面无通用卡片堆叠感，竹简、鼓谱和场景形成统一视觉。
