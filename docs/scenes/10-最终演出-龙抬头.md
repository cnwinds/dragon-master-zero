# 场景10：最终演出——龙抬头

场景ID：`PerformanceScene / final`  
目标时长：30–42秒  
核心目的：用一段连续、可读、不可直接接管的演出兑现前两轮训练，并完成全游戏的情绪高潮  
情绪：盛大期待 → 风险累积 → 突发静默 → 自主选择 → 对应结局

## 0. 共用形象引用

- 阿零：`CHR-AZERO-001 / LOD-HERO`，完整回望调用 `AZ-LOOKBACK-FULL`，高点调用 `AZ-HIGHPOINT-01`。
- 竹青舞龙：`PROP-DRAGON-001 / LOD-HERO / DRG-ACC-FESTIVAL`，与首页英雄画面是同一母版。
- 小满使用 `CHR-XIAOMAN-001 / LOD-HERO` 的绊倒与恢复姿态；三名队员顺序固定。
- 两枚记忆签始终连接 `memory.slot.1/2`，演出中不得漂浮到其他位置。
- 三条结局分支只改变动作、受力和灯光，绝不改变角色与龙具造型。

## 1. 不可破坏的原则

1. 终局自主决策必须来自动作、口令和记忆，不能由玩家在现场选择。
2. 小满受阻、蓝线仍向前、阿零停顿、实际轨迹变化必须在一个连续镜头中完成。
3. 冠军机器路径不发生自主回望。
4. 真正出师路径的回望必须带动头、躯干、龙头和龙身，不是扫描动作。
5. 玩家可在自主决策后纠偏节奏，但不能改变已经作出的价值选择。

## 2. 画面布局

### 演出区域

位置：`x=0 / y=0 / w=1920 / h=850`

- 河岸舞台横向展开。
- 左侧为起势区。
- 中央为灯桥和终局灯绳。
- 右侧为高点区与最亮观众灯海。
- 河面占 `y=700–930`，显示低频倒影。
- 阿零在演出过程中保持在画面横向35%–58%。
- 小满在终局事件前始终处于同一画面。

### 精简时间轴

位置：`x=190 / y=878 / w=1330 / h=116`

- 八拍谱只显示动作图形、当前拍和已完成状态。
- 不显示风险文字。
- 突发事件不占用独立拍位，也不提前标记。
- 决策停顿时时间轴保持冻结，不跳拍。

### 纠偏鼓面

位置：`x=1600 / y=850 / w=230 / h=185`

- 两枚令牌。
- 第一次窗口在终局事件前。
- 第二次窗口只在阿零自主决策后出现。
- 决策期间鼓面完全熄灭，任何点击无效且不消耗令牌。

### 状态提示

左上：`x=70 / y=58 / w=420 / h=90`

- 两条记忆以小型竹签显示。
- 口令只显示一句摘要。
- 演出8秒后整体淡至30%。

右上：`x=1430 / y=58 / w=420 / h=90`

- 三个公开目标图标。
- 不显示分数、结局或隐藏状态。

## 3. 舞台光影

### 基础照明

- 夜靛青环境光。
- 舞台灯笼提供旧铜金主光。
- 月光从左后方提供冷色轮廓。
- 河面倒影低于实体亮度55%。

### 动态照明

- 成功高点时右侧灯海亮度增加12%。
- 脱节时不把全屏变红，只让第一节张力线和附近灯光短暂失衡。
- 突发事件发生时环境灯降低8%，高点灯仍保持明亮，形成视觉诱惑。
- 真正出师回望后，灯光从只照龙头扩展到整条龙身。

## 4. 演出总时间线

以下时间以默认八拍方案为基线。不同动作允许总时长±4秒，但关键事件顺序不变。

### 0.0–3.5秒｜正式开场

- UI从编舞态收拢。
- 周师傅站在右后方，鼓槌抬起。
- 人群声降至低频背景。
- 0.8秒完全安静后，第一声鼓落下。
- 舞台金光从龙头向龙尾逐节点亮。
- 摄像机为全队横向全景。

### 3.5–9.0秒｜前两拍：建立可信度

- 阿零执行前两项动作。
- 蓝图预测线提前150毫秒出现。
- 竹青实际轨迹根据训练侧重产生可见差异。
- 第一条记忆满足条件时触发，但不显示大字。
- 镜头水平跟随，不切近景。

目的：

- 让玩家确认自己的编排和口令仍在起作用。
- 先给一次成功或可控偏差，为后续突发建立对比。

### 9.0–12.5秒｜第一处风险与纠偏

- 进入中段高风险衔接。
- 若存在中等以上偏差，打开第一次纠偏窗口。
- 正拍使下一动作重新贴近鼓点。
- 不使用纠偏时按原训练继续。
- 纠偏结束后令牌状态收回右下，不停演出说明。

### 12.5–18.0秒｜中段升势

- 执行第3–5拍。
- 龙身逐渐进入完整波形。
- 观众灯海开始回应。
- 摄像机从全景推到阿零、小满和龙头的三人中景。
- 如果协作低，第一节龙身已经出现轻微过紧，但不提前触发剧情。
- 如果表现高，蓝图高点线在右侧更明亮。

### 18.0–19.2秒｜小满受阻

事件发生在第5拍结束与第6拍起势之间。

画面：

- 一根原本可见但不突出的灯绳被风吹低。
- 小满后撤换步时脚踝被灯绳勾住。
- 她的托杆瞬间降低，第一节龙身张力变直。
- 后续队员来不及完全停下，波形开始失序。

可读时间：

- 绊倒原因至少显示0.7秒。
- 不使用慢动作超过0.25倍速。
- 不切到脚部特写后立刻切走；镜头保持阿零与小满同框。

声音：

- 鼓声中止。
- 灯绳绷紧、布面摩擦和一步错拍清晰可闻。

### 19.2–20.0秒｜预测仍向前

- 蓝图预测轨迹继续指向右侧高点。
- 高点灯海保持明亮。
- 蓝线上显示下一动作的机械轮廓。
- 竹青实际轨迹停在阿零当前龙头位置。
- 纠偏鼓面熄灭。

该0.8秒用于明确：机器原计划仍是继续。

### 20.0–21.0秒｜自主决策停顿

- 阿零头部扫描缝先看高点，再扫过第一节张力线。
- 两条记忆签按是否参与决策依次亮起。
- 不出现文字选项、按钮、倒计时或方向提示。
- 摄像机只向阿零推近3%，保持小满在左后方。

### 21.0秒以后｜进入三种行为分支

分支由演出状态机确定。

## 5. 分支A：真正出师

触发前提：

- 自主回望成立。
- 完成度、同心、信任和热度达到对应门槛。

### 21.0–23.0秒｜完整回望

- 阿零先转头，再转肩、躯干和髋部。
- 双手调整托杆角度，龙头随身体回转。
- 竹青实际轨迹第一次明确偏离继续向前的蓝图虚线。
- 轨迹向小满闭合，形成一个保护性的圆弧。
- 蓝图线不立刻消失，让偏离行为可比较。

动作时长不少于1.2秒，不能用瞬间转身。

### 23.0–24.0秒｜小满回应

- 阿零降低第一节张力。
- 小满重新站稳，抬眼确认阿零。
- 她把托杆回到正确高度。
- 后续队员依次恢复波形。

### 24.0–26.0秒｜第二次纠偏窗口

- 周师傅重新落鼓。
- 纠偏鼓面恢复。
- 玩家可用剩余令牌帮助队伍重新落拍。
- 正拍强化节奏，但即使近拍也不取消已经发生的回望。

### 26.0–31.0秒｜共同完成高点

- 阿零不是放弃高点，而是在队伍恢复后重新起势。
- 小满和后续队员共同把龙身送上高点。
- 竹青轨迹在蓝图高点附近重新汇合，但路径更圆润。
- 灯光由龙头扩展到整条龙。
- 观众灯海和鼓点同时达到高潮。

### 31.0–34.0秒｜定格

- 队伍保持完整龙形。
- 河面倒影形成第二条龙弧。
- 摄像机拉回全景。
- 最后一拍后停留2秒，再进入“真正出师”结局。

## 6. 分支B：冠军机器

触发前提：

- 自主回望不成立。
- 热度高且队伍同心低。

### 21.0–22.0秒｜继续前进

- 阿零扫描张力线后仍把头部转回高点。
- 蓝图轨迹保持最亮。
- 竹青实际轨迹重新贴向蓝线。
- 不播放完整躯干回望。

### 22.0–26.0秒｜单点高光

- 阿零独自完成最高幅度动作。
- 镜头被高点吸引，短暂让小满处于画面边缘，但不能完全消失。
- 第一节龙身继续绷紧，后续波形无法完整传递。
- 观众灯海剧烈增强。

### 26.0–29.0秒｜队伍脱节

- 阿零落地精准。
- 小满和后续队员晚半拍收势。
- 朱砂张力线横贯第一节。
- 鼓声和欢呼仍然很响，形成价值反差。

### 29.0–32.0秒｜定格

- 聚光灯只照阿零和龙头。
- 后续龙身落入暗部。
- 蓝图线与竹青线在阿零处重合，但队伍轨迹断裂。
- 进入“冠军机器”结局。

## 7. 分支C：灯散之后

触发：

- 未满足前两种结局。

该结局根据最低状态选择三种演出尾声之一，但共用同一场景。

### 变体1：队形不足

- 阿零迟疑后只转头扫描，没有带动躯干和龙头。
- 小满自行恢复，但队伍失去高点时机。
- 演出勉强收束。

### 变体2：完成度不足

- 阿零完成回望并保护队伍，但后续动作因此前失误无法重新达到高点。
- 队形完整，观众回应克制。

### 变体3：平衡不足

- 阿零试图同时保持高点与回望，动作幅度和节奏都不完整。
- 队伍没有严重脱节，但整段收势不够清晰。

共同结尾：

- 周师傅敲下收束鼓。
- 队伍完成基础停龙姿态。
- 灯会继续，但聚光不落在任何单独角色上。
- 进入“灯散之后”结局。

## 8. 轨迹表现

### 真正出师

- 蓝线继续向前。
- 竹青线偏离、回环、再与高点汇合。
- 最终形成完整、连续的弧。

### 冠军机器

- 阿零处蓝线和竹青线高度重合。
- 龙身后段竹青线断裂。
- 第一节出现朱砂直线。

### 灯散之后

- 蓝线和竹青线局部偏离。
- 不形成完整回环或完整断裂。
- 根据最低状态保留对应朱砂或雾灰标记。

## 9. 摄像机

终局事件从18.0秒到分支确定后至少24.0秒保持连续镜头。

允许：

- 水平跟随。
- 3%以内推近。
- 真正出师共同高点时拉回全景。

禁止：

- 切脚部特写后切阿零脸部。
- 使用快速蒙太奇掩盖动作因果。
- 在自主决策时切到UI特写。
- 用慢动作替代清晰动画。

## 10. 用户交互

允许：

- 第一次风险纠偏。
- 自主决策后的第二次纠偏。
- 暂停，但19.2–23.0秒决策段按下暂停时先完成当前0.3秒动作再停。
- 静音。

不允许：

- 决策期间纠偏。
- 点击小满命令阿零回头。
- 使用方向键改变路线。
- 跳过终局事件。

首次通关不可跳过18.0秒后的关键段；重演时允许长按跳至结局分支起点。

## 11. 声音

### 开场

- 全队脚步、龙身布料、鼓点和观众底声形成四层。

### 突发

- 鼓声硬切停止。
- 灯绳和布料声音前置。
- 环境声降低8dB。

### 决策

- 只保留阿零关节、蓝图脉冲和一声很轻的竹片记忆音。
- 不使用煽情弦乐提示“正确答案”。

### 真正出师

- 回望时加入竹材回响。
- 小满站稳后脚步重新落拍。
- 共同高点恢复鼓、锣、龙身和观众四层声音。

### 冠军机器

- 高点鼓和欢呼最响。
- 后段加入轻微不齐的脚步，形成不安。

### 灯散之后

- 收束鼓较轻。
- 环境声逐渐回来。
- 不使用失败音乐。

## 12. 手机横屏

- 终局事件强制采用更宽全景，保证阿零和小满同框。
- 时间轴缩小并降低透明度。
- 决策期间隐藏所有非必要HUD。
- 鼓面只在窗口出现，避免遮挡小满。
- 关闭动态软阴影时，使用轮廓明度保证角色可读。

## 13. 素材

- 河岸舞台完整演出灯光。
- 八拍全部动作组合接口。
- 小满绊灯绳、失衡、恢复动画。
- 三种自主策略动画。
- 真正出师完整身体回望。
- 冠军机器高点与脱节。
- 灯散之后三种尾声。
- 预测、实际、错误三类轨迹。
- 观众和灯海三档反应。
- 河面最终倒影。

## 14. 验收

- 不看字幕时，4/5玩家能看懂小满为何受阻。
- 决策段没有任何可点击行为选项。
- 真正出师的回望持续不少于1.2秒，并带动全身与龙头。
- 冠军机器路径绝不发生完整自主回望。
- 三种结局的3秒无字片段能够被4/5玩家区分。
- 玩家纠偏不能改写已经作出的自主决策。
- 终局事件使用连续镜头。
- 蓝图向前与竹青回环的对比在320×180缩略图中仍可辨认。
- 至少4/5玩家认为终局是全程最明确的情绪高潮。
