# 场景13：结局——灯散之后

场景ID：`EndingScene / after-the-lights`  
目标时长：35–65秒  
核心目的：为所有尚未达到“共同完成”或“高热度脱节”的状态提供诚实、非惩罚性的继续学习结局  
情绪：安静、略有遗憾，但保留继续训练的希望

## 1. 进入条件

- 未命中“真正出师”。
- 未命中“冠军机器”。

该结局根据本局最低状态选择对应尾声，避免叙事与玩家行为相反。

## 2. 主画面基线

- 演出已完成基础停龙姿态。
- 舞台主灯逐渐熄灭，环境灯仍在。
- 观众缓慢散去，不出现嘘声。
- 河面保留稀疏灯影。
- 阿零、周师傅、小满和完整龙身都在画面内。

构图：

- 阿零位于 `x=1050 / y=680`。
- 小满位于 `x=820 / y=710`。
- 周师傅和鼓位于 `x=470 / y=720`。
- 龙身以较低弧度横贯画面。
- 左上留出结局标题。

## 3. 三种叙事变体

### 变体A：队形仍需学习

触发：

- 队伍同心是三项隐藏状态中的最低项。

画面：

- 第一节龙身仍有轻微不均匀张力。
- 小满和阿零共同把龙头放回支架。
- 阿零扫描自己与小满的步距。

周师傅：

> “你看见了路线，还没完全看见队伍。”

训练报告重点：

- 未触发的协作记忆。
- 高风险动作前缺少回望。
- 纠偏只能修节奏，不能替代队形准备。

### 变体B：动作仍需完成

触发：

- 最终完成度最低，且队伍同心不低于55。

画面：

- 队伍保持完整，但龙头没有达到高点。
- 小满先把托杆稳住，再和阿零一起检查动作谱。
- 竹青轨迹连续但高度不足或收势不完整。

周师傅：

> “你已经知道该等谁。下一次，也要把动作走完。”

训练报告重点：

- 未完成的硬目标。
- 失误恢复。
- 节奏或稳定的最低项。

### 变体C：精彩与分寸尚未平衡

触发：

- 没有单项极低，但未达到真正出师门槛。

画面：

- 阿零做出部分回望或减速，但后续高点收势不完整。
- 队伍没有严重脱节。
- 观众回应平稳，不形成高潮。

周师傅：

> “你已经会停，也会冲。还差把它们放在同一拍里。”

训练报告重点：

- 两条记忆之间的冲突或未同时触发。
- 表现与协作的取舍。
- 终局自主策略为何不完整。

## 4. 进入动画

### 0–2秒

- 最终演出姿态保持。
- 主舞台灯从100%降至55%。
- 观众声音缓慢回落。
- 不使用突然黑屏。

### 2–5秒

- 工作人员远景开始收灯。
- 两盏纸灯依次熄灭，形成“灯散”意象。
- 竹青实际轨迹留在地面，蓝图线完全淡出。

### 5–8秒

- 周师傅敲下一声收束鼓。
- 队伍把龙身降低到休息高度。
- 根据最低状态进入对应变体动作。

## 5. 重要显示元素

### 5.1 结局标题

位置：`x=128 / y=120 / w=650 / h=180`

- 主标题：`灯散之后`
- 副标题根据变体切换：
  - 队形：“下一次，先把身后的人放进路线。”
  - 完成度：“下一次，把学会的动作完整走完。”
  - 平衡：“下一次，让精彩和分寸落在同一拍。”

标题使用米白，不使用朱砂“失败”印章。

### 5.2 下一轮训练条目

位置：`x=128 / y=390 / w=650 / h=270`

只列三项：

1. 本局做对的一件事。
2. 最关键的未完成项。
3. 下一轮可尝试的具体动作或口令。

示例：

- 已做到：回望后队伍间距恢复。
- 未完成：最后高点收势过早。
- 可尝试：保留协作侧重，提高节奏而非继续提高稳定。

### 5.3 操作

位置：`x=128 / y=760 / w=620 / h=205`

按钮：

1. `调整最终编排`
2. `重演最终演出`
3. `返回首页`

该结局默认焦点在“调整最终编排”，鼓励再次尝试但不强迫。

## 6. 角色动画

### 阿零

- 不做低头沮丧的人类化表演。
- 根据变体检查队距、动作谱或两条记忆签。
- 说一句客观复盘：

> “训练尚未结束。已记录下一项差异。”

### 小满

- 队形变体：主动示范正确步距。
- 完成度变体：和阿零一起抬一次较低的龙头。
- 平衡变体：用托杆轻敲节拍，提示两种动作衔接。

### 周师傅

- 不宣布失败。
- 最后把鼓槌放在鼓面上，留下“下一拍”的视觉暗示。

## 7. 训练报告

点击下一轮条目可展开详细报告：

- 最终动作谱。
- 口令侧重。
- 两条记忆触发情况。
- 最低状态对应的具体行为。
- 一条可复现的改进建议。

报告不得泄露精确结局阈值。

## 8. 返回最终编排

点击“调整最终编排”：

- 保留上一版动作、口令和记忆。
- 返回最终准备场景。
- 高亮本结局指出的一个关键问题。
- 玩家可以忽略建议，继续自由调整。

不要求重新完成前两轮。

## 9. 声音

- 主舞台锣鼓逐渐远去。
- 保留河水、收灯脚步和灯纸声音。
- 收束鼓为单声，不接失败旋律。
- 不同变体使用相同主题的轻微配器变化：
  - 队形：脚步节拍更清楚。
  - 完成度：竹杆与鼓边音更清楚。
  - 平衡：两种节奏声部短暂错开后停止。

## 10. 手机横屏

- 标题左上。
- 角色与完整低龙形占右侧65%。
- 下一轮训练条目改为三行简报。
- 操作按钮横排，主按钮“调整最终编排”宽度最大。
- 报告展开时暂停背景收灯动画。

## 11. 素材

- 河岸收灯背景状态。
- 三种角色尾声动画。
- 低龙形待机。
- 三套副标题和训练条目模板。
- 详细训练报告。
- 返回最终编排的高亮提示。
- 安静结局音频。

## 12. 验收

- 尾声变体与本局最低状态一致。
- 不出现玩家未做过的保护、高光或失误描述。
- 结局不使用失败印章、嘘声或惩罚性音乐。
- 玩家可直接返回最终编排，不必重做前两轮。
- 至少4/5玩家能说出下一次想改变的具体行为。
- 无字幕画面能够与冠军机器的聚光高热度明确区分。
