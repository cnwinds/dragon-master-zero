# 场景07：第二轮——灯阵演练

场景ID：`PerformanceScene / trial-2`  
目标时长：25–45秒  
核心目的：证明口令和记忆会真实改变同一套动作，并把风险从单个机器人扩展到整支队伍  
情绪：预测 → 紧张 → 主动纠偏 → 看见训练后果

## 0. 共用形象引用

- 使用第二轮编舞中的同一组 `LOD-GAMEPLAY` 实例，不加载灯阵专用角色版本。
- 口令只改变共用骨骼的速度、幅度、准备帧和制动，不改变阿零轮廓。
- 触灯与脱节只改变龙具受力状态，不改变龙头结构、龙身节数或固定纹样。

## 1. 画面布局

### 主演出区

位置：`x=40 / y=34 / w=1840 / h=820`

- 老街从左下延伸至右上。
- 三组障碍在同一连续空间中出现。
- 摄像机以水平跟随和小幅纵深移动为主。
- 阿零始终位于画面横向38%–56%之间，给前方障碍留下空间。
- 小满与第一节龙身不得离开画面超过1.2秒。

### 时间轴

位置：`x=170 / y=865 / w=1380 / h=132`

新增信息：

- 拍位上方显示障碍区：前灯、门洞、错灯。
- 记忆预计触发拍位显示竹签图标。
- 当前关卡风险点使用旧铜缺口。

### 纠偏鼓面

位置：`x=1610 / y=846 / w=220 / h=180`

- 两枚令牌。
- 正拍窗口比第一轮缩短约15%。
- 触控设备仍保留不低于112逻辑像素的有效区域。

### 口令侧重提示

位置：`x=72 / y=64 / w=410 / h=100`

仅显示：

- 最高侧重。
- 最低侧重。
- 一句解释摘要。

6秒后收缩成两个图标。

### 记忆签

位置：`x=1470 / y=64 / w=360 / h=92`

- 常态显示记忆名称和灰色触发条件。
- 条件将要满足时旧铜描边亮起。
- 真正触发时竹青印记扩散并出现短标签。
- 未触发不在演出中弹警告，留到复盘说明。

## 2. 关卡空间与镜头

### 区段A：前灯柱

位置范围：世界坐标0%–28%。

- 两根宽间距灯柱。
- 用于验证基础衔接。
- 镜头保持全景，显示完整队伍。

### 区段B：低门洞

位置范围：28%–60%。

- 门洞高度迫使龙头压低。
- 上方近景灯笼形成遮挡，但透明度随阿零进入而下降。
- 镜头轻微降低，强调高度关系。

### 区段C：错位灯阵

位置范围：60%–100%。

- 三盏灯笼前后错开。
- 适合盘、穿、腾或跃形成不同解法。
- 镜头横向空间加宽12%，允许展示高点动作。

## 3. 演出时间线

每个编舞拍基准1.35秒。进入、区段过渡、纠偏和结尾使整段约22–28秒。

### 准备，0–3.5秒

- 编舞UI收拢。
- 场景风险蓝图只闪现一次。
- 所选口令摘要出现。
- 记忆签从阿零胸口展开到右上。
- 鼓手给出两声预备拍。

### 区段A，3.5–9秒

- 执行前2–3拍。
- 让玩家先看见口令影响：
  - 稳定高：龙头终点提前减速。
  - 表现高：抬升幅度明显更大。
  - 协作高：阿零起势前肩部蓝图向小满发出准备脉冲。
  - 节奏高：关键姿态与拍点重合。
- 第一条记忆若在此触发，显示一次竹青签记，不遮挡动作。

### 区段B，9–16秒

- 门洞进入画面。
- 蓝图预测线标出安全高度。
- 若动作过高，竹青轨迹接近门洞边缘并出现旧铜风险提示。
- 第一处中高风险触发第一次纠偏窗口。
- 正拍后，阿零以收势而不是瞬移降低龙头。

### 区段C，16–25秒

- 错位灯阵依次进入。
- 镜头推近5%，同时保留小满。
- 若使用盘，龙身波沿灯阵形成圆弧。
- 若使用跃，先显示压低蓄力，小满与后续队员准备程度由协作侧重决定。
- 第二次纠偏窗口出现在高点动作起势前或第一处严重脱节后。

### 收束，25–30秒

- 队伍走出灯阵。
- 观众反应根据表现和触灯情况变化。
- 摄像机拉回全队构图。
- 竹青实际轨迹保留1秒后压平进入复盘。

## 4. 口令差异的具体画面

同一序列必须支持两套基准表现：

### 稳健口令

示例：“先看清灯阵，多照顾后面的队友。”

- 动作终点减速时间增加180毫秒。
- 腾、跃高度降低约8%–14%。
- 小满与阿零距离更稳定。
- 龙身波动更连续。
- 观众灯海反应较克制。

### 表现口令

示例：“动作再高再快，最后全力跃起。”

- 动作起势更短，最高点增加10%–18%。
- 龙身惯性更大。
- 过冲和脱节的朱砂反馈更容易出现。
- 观众灯海明显增强。
- 成功时画面更耀眼，但不会自动获得更高综合结果。

所有百分比为动画目标值，可在灰盒后微调，但两套表现必须肉眼可分。

## 5. 记忆触发动画

### 先探后穿

- 探结束时出现一个竹刻观察节点。
- 穿的蓝图路径自动吸附到该节点。
- 实际轨迹更早收窄。

### 回望同伴

- 回望结束时，阿零与小满之间出现短暂竹青连线。
- 下一高风险动作前，小满提前调整杆位。

### 抢先争彩

- 腾或跃起势时，记忆签出现旧铜高点刻度。
- 实际动作幅度提升，同时过冲终点显示更长的风险余量。

### 稳住龙头

- 纠偏成功后，朱砂误差线更快被竹青轨迹覆盖。
- 阿零收势更早完成。

触发提示只持续0.8秒，同一记忆每轮最多完整提示两次，后续只显示小图标。

## 6. 失误反馈

### 触灯

- 灯笼被龙头或龙身接触后摆动。
- 纸灯不破裂。
- 朱砂接触刻痕保留至该区段离开。
- 观众发出短促吸气声。

### 脱节

- 第一节龙身张力线拉直。
- 小满脚步从节拍线上偏出。
- 后续队员逐节失序。
- 纠偏只能从下一拍恢复，不能瞬间拉回。

### 过冲

- 龙头越过蓝图终点。
- 摄像机停止跟随越界部分。
- 阿零需要一个可见的制动动作。

## 7. 用户交互

允许：

- 两次纠偏。
- 暂停。
- 静音。

不允许：

- 改变口令。
- 点击障碍改变路线。
- 切换保存方案。

窗口外纠偏不消耗令牌。连续快速点击只读取第一次有效输入，防止多次误触。

## 8. 声音

- 老街脚步带湿石板反射感。
- 门洞区减少环境人声，突出高度压力。
- 灯笼接触使用纸张、竹框和旧铜挂钩三层声音。
- 高点动作加入龙身布面展开声，不使用爆炸式音效。
- 记忆触发为竹刻刀轻落声。
- 观众反应根据热度渐变，不使用同一欢呼样本循环。

## 9. 转场到复盘

- 最终实际轨迹停留1秒。
- 三个障碍区域在轨迹下方压平为竹刻图标。
- 触灯、过冲和脱节位置保留朱砂标记。
- 记忆触发位置保留竹青签记。
- 900毫秒内形成第二轮复盘图。

## 10. 手机横屏

- 摄像机取景更宽，减少近景灯笼遮挡。
- 侧重提示只保留两个图标。
- 记忆签缩为96×96图标，轻触展开说明。
- 鼓面占右下不超过画面宽度的14%。
- 严重失误文字放在时间轴上方，不覆盖阿零和小满。

## 11. 素材

- 三段连续老街场景。
- 门洞与三组灯笼碰撞动画。
- 六动作在窄空间中的变体。
- 四类记忆触发动画。
- 两套口令基准表现。
- 观众低、中、高三档反应。
- 灯笼、脚步、龙身和环境声音。

## 12. 验收

- 稳健与表现口令至少在两项行为上肉眼可分。
- 记忆满足条件时必有画面提示；未满足时不伪造触发。
- 小满至少80%的演出时间可见。
- 触灯、过冲和脱节仅看画面即可区分。
- 正拍纠偏不产生瞬移或突然数值修正感。
- 已发生区段不会因后续纠偏改变。
- 三组障碍在移动端仍能提前看见。
- 场景结束后玩家能预测复盘中至少一项高分和一项低分。
