# 画面与交互总规范

版本：0.1  
适用：全部场景  
目标：以可控的2.5D网页渲染实现“AAA级感知品质”，重点依靠构图、材质、光影、动画节奏与反馈一致性，而不是堆叠不可控特效

## 1. 画布与坐标

### 1.1 基准画布

- 逻辑分辨率：`1920×1080`。
- 原点：左上角。
- 核心安全区：`x=72 / y=48 / w=1776 / h=984`。
- 标题、正文和关键按钮不得超出核心安全区。
- 场景背景可以延伸到画布之外，用于超宽屏补景。

### 1.2 响应式模式

#### 桌面模式

触发：精细指针设备且视口高度大于500像素。

- 保持1920×1080构图等比缩放。
- 鼠标负责拖放和点击，键盘负责鼓点、跳过与设置。
- 关键按钮最小尺寸：`64×64`逻辑像素。

#### 手机横屏模式

触发：粗指针设备或视口高度不超过500像素。

- 核心画面仍按16:9显示，超宽部分延展环境背景。
- 所有触控目标最小尺寸：`112×112`逻辑像素。
- 正文字号不得低于42逻辑像素。
- 动作栏改为底部抽屉，口令面板改为半屏浮层。
- 刘海和圆角安全区通过CSS `env(safe-area-inset-*)`避让。

#### 竖屏模式

- 不渲染游戏交互。
- 显示低功耗水墨背景、设备旋转图形和“请横置设备”文字。
- 保留声音开关。

## 2. 视觉媒介分工

### 水墨

负责：

- 天空、雾、水面和远景建筑。
- 场景转场。
- 情绪浓淡和空间留白。

限制：

- 不覆盖关键UI。
- 单屏墨迹高频纹理面积不超过35%。
- 动态墨雾速度不超过每秒画面宽度的1.5%。

### 竹刻

负责：

- 角色和龙具外轮廓。
- 近景竹架、窗棂、栏杆。
- 动作竹简。
- 复盘与结局定格。

视觉规则：

- 主轮廓线宽：6–10像素。
- 次级刻线：2–4像素。
- 同一对象刻线方向不超过三组，避免噪声。

### 机械蓝图

负责：

- 阿零的感知范围。
- 预测轨迹。
- 关节测量、动作参数和AI解析。
- 教学辅助。

限制：

- 不出现在普通人的身体上。
- 不作为全屏装饰。
- 非交互状态透明度不高于38%。

## 3. 色彩与材质

### 3.1 固定色板

- 宣纸米白：`#E9E0C8`
- 夜靛青：`#121D2C`
- 朱砂红：`#B64036`
- 旧铜金：`#C79A45`
- 竹青：`#5F8060`
- 蓝图青：`#72A9C2`
- 深墨：`#0A1018`
- 雾灰：`#9AA1A2`

### 3.2 色彩语义

- 蓝图青虚线：预测、机器理解、未执行。
- 竹青墨线：真实动作、已执行、队伍生命感。
- 朱砂折线或叉线：错误、危险。
- 朱砂圆环：可纠偏时机。
- 朱砂方印：复盘评价与结局确认。
- 旧铜金：灯火、成功高点、观众回应。

### 3.3 材质要求

#### 竹材

- 可见纵向纤维、节间色差和细微磨损。
- 高光宽而柔，不呈塑料质感。
- 龙具边缘有真实使用形成的抛光，不做全新道具。

#### 金属

- 银灰拉丝表面，边缘具有暖灯轮廓光。
- 关节内部比护甲暗两个明度等级。
- 禁止镜面铬和过度科幻发光。

#### 纸灯

- 纸纤维可见，光源中心不过曝。
- 近景灯笼具有轻微热形变与风摆。
- 朱砂图案全部原创，不生成可辨识乱码。

#### 水面与湿地

- 倒影采用低频扭曲，不做镜面复制。
- 人物脚下湿地只保留关键轮廓反射。
- 粒子和反射不能遮挡时间轴。

## 4. 字体与排版

- 游戏标题：思源宋体 Heavy 或经过授权的原创标题字。
- 叙事与菜单：思源宋体 SemiBold。
- 参数与数字：IBM Plex Mono，中文回退思源黑体。
- 正文：思源黑体 Regular。

基准字号：

- 首页标题：124。
- 场景章节题：56。
- 主菜单：38。
- 面板标题：34。
- 正文与对话：30。
- 辅助说明：24。
- 参数数字：28。

规则：

- 正文行高为字号的1.55倍。
- 单行中文不超过24字。
- 对话框最多三行。
- UI正文对比度不低于4.5:1。
- 不使用发光描边代替清晰排版。

## 5. 图层

统一层级：

| 层级 | 内容 |
| --- | --- |
| `z=0–49` | 天空、水墨远景、远雾 |
| `z=50–99` | 建筑、竹架、水面、灯光 |
| `z=100–159` | 观众、后续队员、环境道具 |
| `z=160–219` | 阿零、小满、龙头和主要障碍 |
| `z=220–269` | 蓝图预测、竹青轨迹、朱砂错误 |
| `z=270–349` | 常驻HUD、目标、时间轴 |
| `z=350–449` | 教学、高亮、口令与复盘面板 |
| `z=450–549` | 暂停、设置、错误与确认弹层 |
| `z=550–599` | 水墨转场、结局印章 |

任何场景不得临时突破该层级语义。

## 6. 摄像机

- 默认镜头：35毫米等效广角。
- 编舞界面：固定机位，只允许不超过2%的呼吸式推拉。
- 演出镜头：水平跟随为主，推近不超过原构图的18%。
- 禁止快速旋转、手持抖动和超过0.25秒的频闪。
- 角色对话不切传统正反打，使用同一舞台空间内的轻推近维持游戏感。
- 最终回望必须使用连续镜头。

景深：

- 交互阶段关闭强景深。
- 演出近景允许背景模糊半径4–8像素。
- UI下方的场景不得因景深失去障碍可读性。

## 7. 角色标准

### 7.1 阿零

- 身高：画面逻辑比例约178厘米。
- 身体：修长、八头身，肩宽克制。
- 材料：银灰机械骨架，肩、前臂、小腿覆盖竹节护片。
- 头部：无五官，一条水平蓝图扫描缝。
- 识别色：蓝图青扫描、朱砂关节环。
- 待机：重心精确、几乎没有无意义动作。
- 学习后：重心产生轻微呼吸变化，回望时动作由头传到躯干和龙头。

### 7.2 小满

- 年轻龙身手，位于阿零后方第一节。
- 服装：短款竹青训练褂、米白内衬、朱砂束带。
- 剪影：身体轻、前倾、反应快。
- 动画重点：必须让玩家看清阿零动作传导到小满的后果。

### 7.3 周师傅

- 深靛长褂与旧铜护腕，方正稳定。
- 剪影宽而低，站姿不随意晃动。
- 主要动作：敲鼓、抬眼、按住鼓槌、递出旧竹节。
- 不使用夸张仙风道骨造型。

### 7.4 后续队员

- 三名，细节等级低于小满。
- 队服统一，身高与姿态有10%以内差异。
- 动作延迟沿龙身逐节传递，禁止完全同步复制。

## 8. 龙具与骨骼

- 一个龙头、四段龙身、五根托杆。
- 龙头宽约阿零肩宽的1.25倍。
- 龙身主色竹青，腹部宣纸米白，边缘旧铜金，朱砂只作小面积节点。
- 龙头不是活体，不眨眼、不呼吸、不喷火。
- 龙身使用五个主控制点和八个次级柔性点。
- 动作波从阿零传到末段应有80–140毫秒逐段延迟。
- 失去协作时，第一节张力最先改变，后续龙身再逐段失序。

## 9. 轨迹与反馈

### 9.1 预测轨迹

- 线宽：3像素。
- 虚线：18像素实线、12像素间隔。
- 颜色：蓝图青，常态透明度52%。
- 起点附带小型关节编号，演出开始后淡出。

### 9.2 实际轨迹

- 平均线宽：8像素，起止收尖。
- 颜色：竹青。
- 拖尾存留：0.9秒。
- 正确衔接时墨迹连续，失误时墨迹断裂或越界。

### 9.3 朱砂错误

- 抢拍：轨迹领先时间轴的朱砂短刻度。
- 迟疑：起点形成停顿墨点和空拍。
- 过冲：越过蓝图终点的折线。
- 脱节：阿零与小满之间出现拉直的红色张力线。
- 触灯：接触点出现交叉刻痕，灯笼随后摆动。

## 10. 通用UI

### 10.1 面板

- 背景：夜靛青92%不透明度，叠加3%纸纤维。
- 边框：旧铜金1像素，关键面板使用竹刻角标。
- 圆角不超过12像素，避免现代SaaS卡片感。
- 阴影只用于区分层级，模糊半径不超过24像素。

### 10.2 按钮

状态：

- 默认：米白文字、透明背景。
- 聚焦：左侧出现2像素旧铜金刻线。
- 按下：文字向右下移动2像素，响一声竹片音。
- 禁用：透明度38%，显示具体原因。
- 危险操作：朱砂文字，但仍需确认弹层。

### 10.3 动作竹简

- 基准尺寸：`248×92`。
- 左侧为动作单字，右侧为拍数、轨迹小图和风险点。
- 聚焦时向上浮8像素，竹纤维高光移动。
- 合法落点显示竹青槽位。
- 非法落点显示朱砂交叉刻痕和短原因。
- 风险衔接显示旧铜警示刻线，不直接禁止。

### 10.4 对话

- 角色名位于对话文本上方，不使用头像圆框。
- 对话框依附角色所在方向，避免遮挡龙身。
- 点击、空格或触摸继续。
- 长按或设置可切换自动播放。

## 11. 动画规范

帧率基线：60 FPS。

标准时长：

- 按钮反馈：120毫秒。
- 面板进入：280毫秒。
- 面板退出：220毫秒。
- 教学高亮：420毫秒。
- 场景水墨转场：900–1200毫秒。
- 评价印章落下：360毫秒。
- 重大情绪停顿：500–1200毫秒。

缓动：

- UI进入：`cubic-bezier(0.22, 1, 0.36, 1)`。
- UI退出：`cubic-bezier(0.4, 0, 1, 1)`。
- 机械动作：分段线性加速后精确停止。
- 人与龙身：平滑惯性，使用阻尼曲线。

减少动态模式：

- 关闭视差和屏幕震动。
- 墨迹转场改为250毫秒淡入淡出。
- 保留所有玩法反馈。

## 12. 声音与触觉

- UI聚焦：轻竹片擦过声。
- 确认：短促木击。
- 非法操作：低沉竹节闷响。
- 蓝图解析：低音机械脉冲，不使用科幻蜂鸣堆叠。
- 正拍：鼓心厚声。
- 近拍：鼓边声。
- 错拍：闷鼓加轻微朱砂刮擦声。
- 移动端正拍提供一次20–30毫秒轻震；减少动态或关闭触觉时禁用。

## 13. 输入

### PC

- 鼠标左键：选择、拖放、确认。
- 空格：鼓点纠偏、推进对话。
- Escape：暂停。
- Enter：提交口令或确认焦点按钮。
- Tab：遍历HTML输入与设置控件。

### 触控

- 单击动作后单击槽位完成放置。
- 长按动作0.35秒显示详细说明。
- 水平滑动底部抽屉浏览动作。
- 纠偏鼓面固定在右下安全区。
- 禁止依赖双击和多指手势。

## 14. 场景转场

- 首页到序章：标题化为蓝图线，蓝线沿龙杆进入场景，900毫秒。
- 编舞到演练：四区UI向边缘收拢，时间轴保留，650毫秒。
- 演练到复盘：实际轨迹压平为竹刻刀痕，900毫秒。
- 场景地点变化：水墨由近到远洗过画面，1100毫秒。
- 进入结局：保留最后一帧角色姿态，再逐步竹刻化，1400毫秒。

## 15. 性能分级

### 高品质

- 6层视差。
- 动态雾与水面反射。
- 软阴影、局部光和墨迹粒子。
- 完整龙身柔性动画。

### 兼容品质

- 3层视差。
- 静态水面加低频UV扰动。
- 关闭动态软阴影。
- 龙身次级控制点减半。

画质切换不得改变障碍、轨迹或纠偏窗口。

## 16. AAA感知品质验收

- 任一静态截图必须有明确前景、中景、远景。
- 主角、龙头和UI在缩至320×180后仍可辨识。
- 灯光方向、人物阴影和水面反射保持一致。
- 角色轮廓不得依赖发光边描才能看清。
- 每个交互状态都有视觉、声音和文字中的至少两种反馈。
- 动画不允许匀速滑动、瞬间切换或无惯性停顿。
- 所有正式纹样、字体、声音和生成素材具有来源记录。
