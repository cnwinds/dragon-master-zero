# 核心形象与复用资产规范

版本：0.1  
适用：全部场景、美术母版、程序化绘制、概念图、宣传图、动画与截图  
目标：确保首页、训练、演出、复盘和结局中的阿零、龙具及舞龙队始终是同一组形象

## 1. 规范优先级

本文件是共用形象的唯一视觉来源。

发生冲突时，按以下优先级处理：

1. 本文件中的母版比例、识别特征、颜色和锚点。
2. [画面与交互总规范](00-画面与交互总规范.md)中的媒介、图层和动画规则。
3. 各场景文件中的姿态、位置、镜头和光照。

场景文件只允许决定：

- 角色在画面中的位置和缩放。
- 当前姿态与动画状态。
- 摄像机角度。
- 环境光、轮廓光和整体调色。
- 细节等级。
- 剧情明确要求的记忆签、旧竹节等可追踪附件。

场景文件不得单独改变：

- 身体比例和轮廓。
- 龙头骨架、角、眼、吻部和纹样。
- 服装版型与固定配色。
- 标志性磨损与修补位置。
- 托杆、龙身节数和队员顺序。
- 为了构图方便临时增加发光、五官或装甲。

## 3. 母版、实例与细节等级

### 3.1 三层结构

每个共用形象由三层组成：

1. **母版 `Master`**：比例、轮廓、颜色、材质、纹样、锚点和固定磨损。
2. **状态 `State`**：姿态、动作、受力、记忆签数量和剧情附件。
3. **场景实例 `Instance`**：位置、缩放、镜头、光照、阴影和调色。

示例：

```text
CHR-AZERO-001
  Master: 同一身体和材质
  State: lookBackFull + memoryTags=2
  Instance: FinalPerformance / x=1050 / scale=0.82 / warmRimLight
```

### 3.2 细节等级

| 等级 | 使用场景 | 可删减内容 | 不可删减内容 |
| --- | --- | --- | --- |
| `LOD-HERO` | 首页、终局关键镜头、结局 | 不删减 | 完整轮廓、材质、刻线、固定磨损 |
| `LOD-GAMEPLAY` | 编舞、演练、正式演出 | 微小划痕、二级纤维 | 轮廓、关节环、服装版型、龙纹 |
| `LOD-THUMB` | 复盘缩略、报告、图标 | 内部材质与次级线 | 头肩轮廓、主色、识别标记 |
| `LOD-SILHOUETTE` | 远景、观众、加载图形 | 内部全部细节 | 外轮廓和关键道具关系 |

降低细节不等于重新设计。不同等级叠加到相同尺寸时，外轮廓偏差不得超过2%。

## 4. 阿零母版 `CHR-AZERO-001`

### 4.1 基准比例

以角色总高 `H=1.00`：

- 总高：178厘米，对应 `H`。
- 头高：`0.115H`。
- 肩高：`0.78H`。
- 肩宽：`0.235H`。
- 胸腔高：`0.20H`。
- 胯宽：`0.145H`。
- 膝高：`0.285H`。
- 脚长：`0.145H`。
- 手臂自然下垂时，腕部位于 `0.43H`。
- 前臂竹节护片长度：`0.16H`。
- 小腿竹节护片长度：`0.20H`。

阿零始终保持修长八头身倾向，不得在首页画成重装机甲、在演出画成细小服务机器人。

### 4.2 正面轮廓

- 头部为窄圆角梯形，上宽下窄。
- 无口、鼻、耳和独立眼睛。
- 水平扫描缝位于头部高度的46%，占头宽68%。
- 颈部暴露两段深墨机械轴。
- 肩甲为短竹节切片，不延伸成夸张翼甲。
- 胸腔中央保留一条竖向深墨结构缝，作为记忆签安装轴。
- 腰部窄，髋部不做外扩装甲。
- 膝、肘和腕部各有一圈朱砂关节标记。

### 4.3 侧面轮廓

- 后脑只比面部扫描面突出头宽的8%。
- 胸腔微向前收，不使用健美式胸甲。
- 背部中央有三段短竹片脊柱护片。
- 小腿后侧机械结构可见，竹片只覆盖前外侧。
- 脚底前后两段结构清楚，便于表现制动和重心。

### 4.4 背面轮廓

- 肩胛间显示深靛机械主梁。
- 三段脊柱竹片由上至下逐渐变窄。
- 右肩背面固定一枚空心圆“零”标记。
- 标记只使用刻线，不发光，不随场景改变位置。

### 4.5 固定颜色与材质

- 主骨架银灰：`#B7C2C8`。
- 次级金属：`#8A97A0`。
- 关节腔深灰：`#3E4A52`。
- 竹片基础色：`#5F8060`。
- 竹片暗部：`#3D5744`。
- 朱砂关节：`#B64036`。
- 扫描缝：`#72A9C2`。
- 深墨结构：`#0A1018`。

固定材质规则：

- 金属是拉丝银灰，不使用镜面铬。
- 竹片有纵向纤维和浅色节线。
- 竹片边缘存在轻微抛光，不能每个场景随机生成磨损。
- 扫描缝只有工作时发光，关闭时仍可看到深色玻璃槽。

### 4.6 固定识别点

以下五点必须在所有可见细节等级中保留：

1. 单条水平蓝图扫描缝。
2. 右肩背面的空心“零”刻记。
3. 前臂和小腿的竹节护片。
4. 膝、肘、腕的朱砂关节环。
5. 胸腔中央的记忆签安装轴。

### 4.7 骨骼与锚点

统一锚点：

- `root`：双脚中点。
- `pelvis`：髋中心。
- `chest`：胸腔中心。
- `neck`：颈轴中心。
- `head`：扫描缝中心。
- `shoulder.L/R`。
- `elbow.L/R`。
- `wrist.L/R`。
- `grip.primary`：右手托杆握点。
- `grip.support`：左手托杆握点。
- `memory.slot.1/2`：胸腔安装轴上下两个插槽。

首页、训练和终局必须使用同一组锚点。不得因为首页构图重新定义手部与托杆连接位置。

### 4.8 姿态库

| 姿态ID | 用途 | 关键要求 |
| --- | --- | --- |
| `AZ-IDLE-01` | 普通待机 | 重心垂直、无拟人呼吸 |
| `AZ-IDLE-LEARNED` | 第二轮后待机 | 髋部重心变化不超过2%，不是呼吸胸口 |
| `AZ-SCAN-FRONT` | 前向扫描 | 只转头，躯干不转 |
| `AZ-SCAN-TEAM` | 序章观察队友 | 头部回扫不超过45度 |
| `AZ-GRIP-READY` | 持龙准备 | 双手固定在共用托杆锚点 |
| `AZ-STRAIN-01` | 队伍脱节 | 手臂受力、髋部制动，不做痛苦表情 |
| `AZ-LOOKBACK-FULL` | 终局完整回望 | 头、肩、躯干、髋、托杆依次回转 |
| `AZ-HIGHPOINT-01` | 高点动作 | 一脚制动、一脚支撑，轮廓清楚 |
| `AZ-RECEIVE-BAMBOO` | 接旧竹节 | 先看小满，再双手接取 |

六种玩法动作由这些基础受力姿态组合，不另建六套不同身体。

### 4.9 可变与不可变

允许变化：

- 扫描缝亮度。
- 关节受力角度。
- 记忆签0、1、2枚。
- 真正出师后增加旧竹节。
- 环境形成的冷暖轮廓光。

禁止变化：

- 改变头型。
- 增加人类眼睛或嘴。
- 首页增加披风、终局增加武器。
- 通过变红眼表达“冠军机器”。
- 训练阶段随机改变竹片数量和位置。

## 5. 竹青舞龙母版 `PROP-DRAGON-001`

### 5.1 物理组成

- 1个龙头。
- 4段龙身。
- 5根托杆。
- 5个主控制点。
- 8个次级柔性点。
- 龙头、四段龙身和托杆在全部场景保持相同数量。

### 5.2 龙头比例

- 母版画幅比例：宽高 `4:3`。
- 颈根旋转锚点：相对画幅 `x=0.30 / y=0.56`。
- 可见宽度约为阿零肩宽的1.25倍。
- 吻部占头部总宽约38%。
- 眼眶中心位于头部宽度64%、高度41%。
- 前角最高点不得超过头部高度的4%画幅边界。

### 5.3 龙头固定造型

遵循南派舞龙彩扎结构，不是南狮，也不是西方龙：

- 鹿角。
- 驼形长吻。
- 虾眼。
- 牛耳。
- 鱼鳞。
- 两条长金须。
- 颌下朱砂髯。

固定识别点：

1. 近侧前角尖端有一处3%长度的旧缺口。
2. 额部有旧铜金双弧火焰纹和一条朱砂竖刻。
3. 近侧眼角有一小块朱砂椭圆。
4. 近侧颊部固定三列鱼鳞刻线。
5. 两条金须一长一短，长须向后回卷。
6. 颈根下方有一道米白修补缝。

以上识别点在首页、演出和结局中必须处于相同相对位置。

### 5.4 固定颜色

- 主体竹青：`#5F8060`。
- 高光竹青：`#8FB894`。
- 深竹青：`#314A38`。
- 额纹、角、背鳍：`#C79A45`。
- 角尖高光：`#E8C98A`。
- 腹部与牙：`#E9E0C8`。
- 髯、舌和眼角：`#B64036`。
- 轮廓深墨：`#1A281F`。

### 5.5 四段龙身

四段使用同一结构母版，但保留可追踪差异：

- 第一节：右下腹有一块米白方形修补。
- 第二节：背鳍第三片略短。
- 第三节：无明显修补，是最标准的一节。
- 第四节：末端有一条朱砂系带。

这些差异用于复盘和脱节镜头确认龙身顺序，不得每场随机交换。

### 5.6 配件状态

基础龙具不更换。

允许的模块化配件：

- `DRG-ACC-TRAINING`：所有节庆流苏收束并固定在杆侧。
- `DRG-ACC-FESTIVAL`：展开原有旧铜金流苏，不增加新结构。

首页与河岸主舞台使用 `DRG-ACC-FESTIVAL`。  
竹棚和老街训练使用 `DRG-ACC-TRAINING`。

切换配件不能改变龙头、鳞片、角、须和龙身长度。

### 5.7 龙具动画

- 龙头不是活体，不主动眨眼、呼吸或喷火。
- 眼部高光只随环境灯移动，不独立追踪玩家。
- 所有运动由托杆、阿零和队员施力产生。
- 龙头动作先于第一节80毫秒。
- 后续每节再延迟80–140毫秒。
- 第一节受力异常必须先于后续失序出现。

### 5.8 竹棚退役龙头

竹棚背景中挂起的旧龙头使用 `PROP-DRAGON-ARCHIVE-001`：

- 它是环境叙事道具，不是阿零正在使用的 `PROP-DRAGON-001`。
- 采用褪色米白与深竹青，缺少一条金须，轮廓比主龙头更传统、更厚重。
- 只出现在竹棚背景，不进入舞龙动作、首页英雄画面和最终演出。
- 场景文档提到“挂起的旧龙头”时必须使用该资产ID，避免误把主龙具复制为背景装饰。

1. 左髋朱砂束带结。
2. 低发髻与短铜簪。

## 8. 后续队员

队员顺序固定：

1. `CHR-TEAM-A01`：第二节，身高168厘米，束带在右侧。
2. `CHR-TEAM-A02`：第三节，身高175厘米，袖口较长。

## 9. 共用道具

### 9.1 旧鼓 `PROP-DRUM-001`

- 鼓面直径与周师傅肩宽相近。
- 深棕鼓身、米白鼓面、旧铜鼓钉。
- 鼓面右下有一道浅修补痕。
- 首页、竹棚、河岸和结局均使用同一面鼓。

### 9.2 托杆

- 龙头杆 `PROP-POLE-001` 比龙身杆长12%。
- 竹色一致，握点使用深靛缠带。
- 小满握点额外有竹青缠带，是角色识别点。
- 杆与手必须连接到统一握点锚点，不能穿手或悬空。

### 9.3 训练记忆签

- 同一尺寸、同一竹材和同一安装方式。
- 第一枚安装在胸腔轴上位，第二枚安装在下位。
- 记忆类型只改变刻纹，不改变签体颜色和轮廓。

### 9.4 出师旧竹节

- 只在“真正出师”结局出现。
- 长度为阿零前臂的70%。
- 材质与龙头颈根修补竹材一致。
- 解锁后首页只允许出现同一旧竹节的小型挂件，不生成新奖章。

## 11. 场景调色规则

母版保存局部固有色，场景只能叠加统一环境调色。

### 竹棚

- 冷色环境覆盖不超过18%。
- 竹青保持可见，不调成灰蓝。

### 老街

- 夜靛环境覆盖不超过28%。
- 暖灯只影响朝灯面，不改变固有色取样。

### 河岸

- 旧铜轮廓光最高可增加25%亮度。
- 聚光不能把竹青洗成金色。

### 结局

- 竹刻化只降低内部饱和度。
- 外轮廓、识别标记和相对颜色关系必须保留。

## 12. 概念图与AI生成一致性

### 12.1 生产顺序

1. 先制作阿零正面、侧面、背面三视图。
2. 再制作龙头正侧视图与四段龙身拆解。
3. 制作小满、周师傅和三名队员设定页。
4. 确认母版后生成首页、训练和终局场景。
5. 场景图不得反向修改母版。

### 12.2 参考图要求

生成任何场景图时必须同时提供：

- 对应角色母版设定图。
- 龙头与龙身母版图。
- 当前姿态参考。
- 当前场景构图草图。

提示词开头必须写：

> Reuse the exact same character and dragon prop designs from the attached master sheets. Do not redesign silhouettes, armor, costumes, horns, facial structure, scale patterns, colors, wear marks, or prop proportions.

### 12.3 禁止依赖纯文字复现

母版确定后，不能只用文字提示词重新生成同一角色。  
每张场景图必须使用锁定的参考图、角色ID和版本号。

### 12.4 生成后修正

AI输出出现以下情况必须人工修正或重生成：

- 阿零多出五官、手指或装甲。
- 龙头变成南狮或西方龙。
- 角、须、额纹或修补位置改变。
- 小满服装、发型或束带位置改变。
- 龙身节数或队员人数变化。
- 托杆与手部断开。

## 13. 程序实现约束

程序渲染同样遵循“一个母版、多场景实例”：

- 阿零只能由一个共用渲染器或纹理工厂生成。
- 龙头与龙身只能由一个共用龙具模块生成。
- 首页不得拥有另一套独立的阿零绘制函数。
- 场景通过参数传入姿态、细节等级、配件和光照。
- 母版颜色、比例和锚点集中在一份资产定义中。
- 修改母版后，首页、训练、演出和结局必须同时更新。

建议接口：

```ts
type VisualLod = "hero" | "gameplay" | "thumb" | "silhouette";

interface AZeroVisualState {
  pose: AZeroPoseId;
  lod: VisualLod;
  memoryTags: 0 | 1 | 2;
  oldBamboo: boolean;
  scanIntensity: number;
}

interface DragonVisualState {
  lod: VisualLod;
  accessory: "training" | "festival";
  tension: number;
  segmentOrder: readonly [1, 2, 3, 4];
}
```

## 14. 版本管理

母版版本格式：

```text
资产ID / Major.Minor
例如：CHR-AZERO-001 / 1.0
```

- `Major`：改变轮廓、比例或识别特征，必须重新审核所有场景。
- `Minor`：材质精修、次级刻线和不改变轮廓的修正。
- 场景文件只记录使用版本，不复制母版参数。
- 宣传截图必须记录母版版本。

## 15. 复用验收

### 静态叠图

- 将首页、第一轮演练、最终演出中的阿零归一到相同高度。
- 外轮廓偏差不得超过2%。
- 右肩“零”、关节环和竹片位置必须重合。

### 龙头比对

- 归一到相同宽度后，角、眼、吻部、额纹和颈根锚点必须重合。
- 固定缺口、修补缝和金须长度关系必须一致。

### 颜色比对

- 在关闭环境调色的母版输出中，固定色值完全一致。
- 场景调色不得导致竹青、蓝图青和朱砂的语义混淆。

### 动画比对

- 首页持杆锚点与演出持杆锚点一致。
- 回望前后托杆不穿手、不脱离龙头颈根。
- 四段龙身顺序和修补标记不交换。

### 场景检查

- 每个场景只列实例状态，不重复定义外观。
- 任何场景专用外观改动都必须有剧情依据和可追踪附件ID。
- 未通过母版审核的场景图不得进入游戏、海报或宣传视频。
