# 场景09：最终演出——准备

场景ID：`TrainingScene / final`  
目标时长：120–180秒  
核心目的：在没有唯一正确答案的情况下，让玩家用全部经验完成最终编排并正式“交付训练”  
情绪：空间豁然打开 → 责任感 → 克制的临场紧张

## 1. 场景目标

公开目标：

- 完成河岸主舞台的八拍演出。
- 至少经过一次高点区域。
- 保持龙身队形完成压轴收束。

隐含冲突通过角色和构图表达，不显示为任务：

- 观众期待高难动作。
- 小满希望队伍保持可控。
- 周师傅不再提供具体顺序。

本轮可用：

- 六种动作。
- 自由训练口令。
- 两条训练记忆。
- 两次演出纠偏。

## 2. 场景空间

地点：河岸灯会主舞台。  
时间：深夜。  
画面尺度：比老街横向扩大约35%。

舞台区域：

- 左侧准备区：队伍起点。
- 中央灯桥：主要舞龙空间。
- 右侧高点区：观众和灯海最密集。
- 下方河面：形成完整倒影。
- 后方石阶：观众剪影。

构图目的：

- 玩家在编排时就能看见高点诱惑。
- 小满始终处于阿零身后可读位置。
- 终局事件所需灯绳在中后景提前出现，但不突出。

## 3. 桌面布局

### 顶部舞台目标

位置：`x=380 / y=32 / w=1160 / h=90`

内容：

- `最终演出 · 龙抬头`
- 三个目标图标。
- 不显示风险总等级。
- 右端显示灯会倒计时，不实时倒数，只写“即将开场”。

### 左侧动作栏

位置：`x=52 / y=132 / w=320 / h=748`

- 六种动作全部可用。
- 每种最多两次。
- 动作下方不再显示基础教学文字。
- 聚焦时仍可查看详细作用和失败版本。
- 已使用次数清晰可见。

### 中央主舞台预演

位置：`x=385 / y=126 / w=1125 / h=568`

画面：

- 阿零和队伍位于左侧准备区。
- 河岸舞台延伸到右侧高点。
- 灯桥形成一个缓慢上升的弧。
- 观众灯海随鼠标聚焦高点动作轻微增强，但不显示分数。
- 河面显示低亮度路径倒影。

### 右侧训练交付面板

位置：`x=1520 / y=126 / w=348 / h=568`

从上到下：

1. 两条记忆：`h=188`
2. 最终口令：`h=220`
3. 阿零理解：`h=120`
4. 交付状态：`h=40`

#### 记忆区

- 两条记忆上下排列。
- 每条显示触发条件。
- 当前编排满足时竹青亮起。
- 两条记忆都未触发时不禁止演出，但在交付摘要中明确提醒。

#### 最终口令

占位文字：

> “最后一次，你希望阿零记住什么？”

建议口令不直接展示在输入框下，改为点击“回看师傅的话”后查看三句故事提示，避免暗示标准答案。

### 八拍时间轴

位置：`x=385 / y=728 / w=1125 / h=210`

新增：

- 第6拍之后以淡朱砂细线标记“高点区”。
- 不标记终局突发事件具体拍位。
- 时间轴下方显示两条记忆的预计触发点。
- 最后一个拍位带“收束”图标，任何动作都可放，但不同动作影响完成度。

### 交付按钮

位置：`x=1530 / y=790 / w=320 / h=102`

文案：`交付训练`

按钮不是“开始演出”，强调玩家将控制权交给阿零。

可用条件：

- 八拍填满。
- 口令解析完成。
- 玩家已查看两条记忆状态。

## 4. 场景角色表现

### 阿零

- 待机不再完全僵直。
- 两条记忆签以实体竹片固定在胸前或腰侧。
- 玩家聚焦某条记忆时，对应竹片轻亮。

### 小满

- 站在阿零身后，检查第一节托杆。
- 编排连续高风险动作时，她看向阿零但不弹出警告对白。
- 协作较高时，她站位更靠近阿零；较低时保留更大安全距离。

### 周师傅

- 位于中央场景右后方。
- 全程不指出具体动作。
- 点击他只说一次：“最后一轮，不是把每一步都替它走完。”

### 观众

- 低细节剪影。
- 玩家聚焦腾、跃时，右侧灯海稍亮。
- 不提前欢呼，不影响玩家判断。

## 5. 编排反馈

### 高点预演

使用腾或跃时：

- 蓝图路径延伸到高点区。
- 河面倒影同步出现一条低亮蓝线。
- 观众灯海增加5%亮度。

### 协作预演

使用回望、盘或探后穿时：

- 小满与后续队员的幽灵姿态更接近连续波。
- 两条记忆若触发，队伍连接点出现竹青节点。

### 冲突预演

连续高风险动作且协作侧重低时：

- 高点路线仍然漂亮。
- 第一节龙身出现旧铜张力提示。
- 不显示“将进入冠军机器”等结局暗示。

## 6. 最终口令

解析流程沿用第二轮，但文案更克制：

- 四项侧重动画完成后不再显示“推荐”。
- 系统解释以阿零口吻复述：“我会先……然后……”
- 解释不得承诺必然回望或必然获胜。

示例：

玩家输入：

> “先看队伍，再一起完成最后的高点。”

阿零理解：

> “协作优先；确认队形后保留一次高点动作。”

侧重仍必须合计200。

## 7. 交付训练确认

点击“交付训练”后出现全宽摘要，位置：

`x=330 / y=210 / w=1260 / h=650`

内容：

1. 八拍动作谱。
2. 四项侧重。
3. 两条记忆及是否满足触发条件。
4. 两个最高风险点。
5. 一句确认：“演出开始后，你只能在鼓点上纠偏，不能替阿零选择。”

按钮：

- `返回修改`
- `确认交付`

确认交付后：

- 两条记忆签进入阿零胸口。
- 动作竹简沿时间轴压成一条完整竹谱。
- 口令化为蓝图线进入头部扫描缝。
- 所有编辑UI逐步退出。

## 8. 动画

### 场景进入

总时长1200毫秒：

- 老街墨色向左右退开。
- 河岸灯海从中央向两侧点亮。
- 镜头由窄街35毫米视角扩展为更开阔的32毫米视角。
- 队伍从左侧走入准备位置。
- 标题“最终演出”只停留2秒。

### 待机

- 河面反射5.8秒低频循环。
- 观众灯海随机轻微呼吸，不形成波浪灯牌。
- 龙身在队员手中保持极小幅度自然摆动。
- 周师傅每12–18秒轻触鼓面检查声音。

### 交付后

- UI退出650毫秒。
- 舞台灯光从环境照明切到演出照明，900毫秒。
- 第一声正式鼓点前保留0.8秒安静。

## 9. 用户交互

- 编排、重排和删除动作。
- 查看两条记忆。
- 输入并解析最终口令。
- 点击舞台障碍查看空间说明。
- 查看交付摘要。
- 确认交付。

不允许：

- 修改记忆选择。
- 查看结局概率。
- 在交付后撤回，除非退出到暂停并选择重新开始最终编排。

## 10. 声音

- 环境加入更近的人群声、河水和舞台木板声。
- 编排阶段音乐只有低频鼓心和拉长的竹弦音。
- 聚焦高点动作时加入短暂金属泛音。
- 聚焦协作动作时加入龙身布料和脚步同步声。
- 交付确认后所有环境声降低6dB，等待第一声鼓。

## 11. 手机横屏

- 主舞台区域占上方58%。
- 动作栏进入底部抽屉。
- 记忆以两个常驻小竹签显示在左上。
- 最终口令使用半屏浮层。
- 交付摘要改为纵向滚动，但确认按钮固定底部。
- 摘要关闭后必须回到原时间轴位置。

## 12. 素材

- 河岸主舞台8层背景。
- 灯桥、观众、河面倒影。
- 最终编排UI。
- 两条记忆实体竹片。
- 高点、协作与冲突幽灵预演。
- 交付摘要。
- 舞台灯光切换。

## 13. 验收

- 玩家能说出“交付训练”意味着接下来不能直接控制。
- 两条记忆的触发状态清晰。
- 不显示结局倾向和突发事件位置。
- 最终口令不会直接返回“将回望”等剧透。
- 交付前所有高风险都有可查看原因。
- 交付后UI完整退出，不遮挡正式演出。
- 至少4/5玩家能在交付前说出自己的最终训练策略。
