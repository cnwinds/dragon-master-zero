# 《龙师零号》场景画面规格索引

版本：0.1  
用途：美术制作、UI实现、动画实现、声音设计、截图与验收的共同基线

## 使用方式

1. 所有场景首先遵循 [画面与交互总规范](00-画面与交互总规范.md)。
2. 每个场景文件给出1920×1080逻辑画布上的位置、尺寸、层级、动画和交互。
3. 坐标均以画布左上角为原点，格式为 `x / y / w / h`。
4. 标注为“动态”的数值可在灰盒测试后微调，但不得改变视觉层级和玩法因果。
5. 场景验收同时遵循 [统一验收标准](../ACCEPTANCE_CRITERIA.md)。

## 核心视觉连续性

- 首页只出现阿零的头部扫描，不提前展示完整“回望”。
- 竹棚阶段以宣纸米白、灰青和蓝图线为主。
- 老街阶段增加夜靛青、朱砂灯笼和空间压迫。
- 河岸阶段打开横向空间，引入完整金色灯海与水面倒影。
- 结局“真正出师”首次完整展示竹青轨迹主动偏离蓝图预测线。

## 不可破坏的画面规则

- 蓝图虚线只表示机器预测与感知。
- 竹青墨迹只表示实际动作与生命感。
- 朱砂折线只表示危险或错误；圆形表示纠偏；方印表示评价。
- 背景不得抢过阿零、龙头、八拍时间轴和当前交互。
- 终局自主决策时不得出现可点击的“回望”按钮。
