# 场景14：暂停、设置与系统状态

场景ID：`SystemOverlay`  
适用：全部场景  
核心目的：在不破坏水墨竹刻视觉的前提下处理暂停、设置、加载、联网降级、确认和设备方向

## 1. 暂停层

### 触发

- PC按Escape。
- 桌面点击右上暂停。
- 手机点击左上暂停。
- 浏览器失去焦点时，编排和复盘不自动暂停；演出中自动暂停并显示原因。

### 背景处理

- 游戏画面冻结。
- 饱和度降低30%。
- 叠加夜靛青76%透明遮罩。
- 不使用高斯模糊超过6像素，保留当前上下文。
- 音乐在180毫秒内降至-18dB，环境音降至-12dB。

### 暂停面板

位置：`x=610 / y=180 / w=700 / h=720`  
层级：`z=470`

样式：

- 深靛竹纸底。
- 旧铜1像素边框。
- 上方标题“暂停训练”。
- 左侧竖向菜单，右侧显示当前选项说明。

菜单：

1. 继续
2. 设置
3. 重新开始当前阶段
4. 返回首页

“重新开始”和“返回首页”使用朱砂文字，但不填充红色按钮。

### 交互

- Escape再次关闭。
- 点击遮罩不关闭，避免误操作。
- 上下键切换，Enter确认。
- 演出暂停恢复时，从下一完整鼓拍继续，并提供两声预备拍。

## 2. 设置面板

位置：`x=460 / y=110 / w=1000 / h=860`

### 左侧分类

位置：`x=500 / y=180 / w=260 / h=690`

分类：

- 声音
- 画面
- 操作
- 字幕与辅助
- AI与隐私

### 右侧内容

位置：`x=800 / y=180 / w=600 / h=690`

控件统一：

- 行高76。
- 标签左对齐。
- 控件右对齐。
- 滑杆有效宽度280。
- 切换按钮尺寸96×48。
- 每项下方最多一行说明。

## 3. 声音设置

项目：

- 总音量。
- 音乐。
- 音效。
- 环境声。
- 触觉反馈，仅支持设备显示。

行为：

- 调整滑杆实时试听，但鼓点试玩不超过一次。
- 静音后保留所有视觉节拍提示。
- 恢复默认需要二次确认。

## 4. 画面设置

项目：

- 画质：高品质 / 兼容。
- 全屏，仅桌面。
- 减少动态。
- 屏幕震动：开 / 关。
- 轨迹对比增强。

轨迹对比增强：

- 蓝图虚线增加1像素外缘。
- 竹青实际线增加米白细边。
- 朱砂错误增加叉形节点。
- 不改变游戏规则。

减少动态：

- 关闭视差。
- 关闭环境粒子。
- 水墨转场改为淡入淡出。
- 保留角色关键动作和纠偏圆环。

## 5. 操作设置

项目：

- 鼓点键位，默认空格。
- 对话推进键，默认空格或Enter。
- 拖放辅助：开 / 关。
- 点击放置：始终开启，不能关闭。
- 纠偏窗口辅助：标准 / 宽松。

宽松模式：

- 正拍窗口扩大25%。
- 不改变剧情门槛。
- 训练报告标注使用辅助，但不影响参赛演示。

键位修改：

- 点击后进入等待输入。
- Escape取消。
- 与浏览器保留快捷键冲突时拒绝并说明。

## 6. 字幕与辅助

项目：

- 字幕速度：慢 / 标准 / 快 / 自动。
- 字幕背景：低 / 中 / 高。
- 字号：标准 / 大。
- 色觉辅助：默认 / 红绿色觉增强 / 蓝黄色觉增强。
- 自动推进对白。

规则：

- 大字幕不超过三行。
- 重要动作说明不只通过颜色传达。
- 色觉模式主要改变线型和形状，不只替换颜色。

## 7. AI与隐私

显示：

- 当前模式：在线理解 / 固定缓存 / 本地理解。
- 在线服务地址只显示域名，不显示密钥或完整路径。
- 一句说明：“联网模式会把训练口令发送给所配置的模型服务。”

设置：

- 允许在线解析：开 / 关。
- 清除口令缓存。
- 查看AI使用说明。

关闭在线解析后：

- 立即切换本地规则。
- 不影响存档和结局。
- 不弹出警告。

## 8. 加载画面

### 首次加载

- 背景：宣纸米白上的一条未完成竹刻龙线。
- 进度每增加，龙线从龙尾向龙头刻出。
- 中央不显示旋转菊花。
- 底部显示当前加载类别：场景、角色、声音、准备完成。
- 若加载超过5秒，显示“正在整理训练场”。

位置：

- 龙线：`x=360 / y=360 / w=1200 / h=260`
- 进度：`x=560 / y=720 / w=800 / h=18`
- 状态：`x=560 / y=760 / w=800 / h=50`

加载完成后：

- 最后一刀刻出龙眼。
- 画面以水墨淡入首页。

### 场景加载

- 不切全屏加载页。
- 使用水墨转场遮挡资源切换。
- 超过1.5秒时，在右下显示小型竹刻进度。

## 9. 横屏提示

触发：粗指针设备且高度大于宽度。

画面：

- 低功耗靛青水墨背景。
- 中央为手机轮廓和一条竹青龙身，从竖向转成横向。
- 文案：“请横置设备，继续训练。”
- 下方提供声音开关。

位置：

- 图形：`x=610 / y=230 / w=700 / h=420`
- 文案：`x=510 / y=700 / w=900 / h=80`

设备转为横屏后，250毫秒淡出并恢复原场景。

## 10. AI状态提示

### 在线理解

- 蓝图青小点。
- 文案只在口令面板显示。

### 固定缓存

- 旧铜小点。
- 文案“已用训练记录”。

### 本地理解

- 竹青小点。
- 文案“当前使用本地训练解析”。
- 不使用红色、警告三角或失败音。

### 在线超时

- 4秒后自动本地解析。
- 页面底部出现3秒轻提示：“在线理解暂不可用，已切换本地解析。”
- 不需要玩家确认。

## 11. 错误与确认

### 非阻断提示

位置：`x=620 / y=930 / w=680 / h=76`

- 3秒自动消失。
- 可手动关闭。
- 包含具体结果和下一步。

示例：

- “口令过长，已保留前40个字。”
- “在线理解暂不可用，已切换本地解析。”

### 阻断错误

仅用于：

- 核心资源加载失败。
- 存档无法恢复且无法安全重置。
- Canvas上下文无法恢复。

位置：`x=500 / y=280 / w=920 / h=520`

必须包含：

- 用户能理解的错误。
- 已保护的数据。
- 可执行操作：重试、清除异常存档、返回首页。
- 错误编号，供开发排查。

不得显示堆栈。

### 危险确认

用于：

- 重新开始。
- 返回首页并放弃当前未保存编排。
- 清除全部进度。

结构：

- 明确会丢失什么。
- 主按钮使用米白。
- 危险按钮使用朱砂文字。
- 默认焦点放在取消。

## 12. 存档提示

- 自动保存发生在编排确认、复盘记忆确认和结局进入时。
- 保存图标为小型竹签刻痕，位于右上。
- 保存中显示刀痕逐步刻下。
- 保存完成后停留0.8秒。
- 保存失败时提供重试，不阻断当前场景。

## 13. 用户交互与焦点

- 弹层打开时焦点限制在弹层内。
- 关闭后返回触发控件。
- Tab顺序与视觉顺序一致。
- 触控滚动不触发背景拖放。
- 系统弹层层级高于场景UI，低于浏览器原生输入法。
- 任何关闭按钮触控区域不小于112逻辑像素。

## 14. 声音

- 暂停打开：低沉木击。
- 设置分类切换：竹片轻擦。
- 切换项：短机械卡位声。
- 危险确认：低鼓边，不使用警报。
- 加载完成：竹刻刀收尾与一声轻鼓。
- 错误：纸张短促撕裂感，但音量低。

## 15. 验收

- 演出暂停恢复时不会错过纠偏窗口。
- 在线关闭、超时和无密钥均可完整游戏。
- 设置不暴露API密钥。
- 竖屏提示不会丢失当前进度。
- 所有危险操作默认焦点为取消。
- 减少动态模式保留全部玩法信息。
- 静音模式仍能完成节奏纠偏。
- 键盘焦点可见，弹层不会焦点逃逸。
- 1366×768和手机横屏下设置内容可完整访问。
